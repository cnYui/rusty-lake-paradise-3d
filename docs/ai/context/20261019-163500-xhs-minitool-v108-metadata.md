## 需求（用户）

“简介写成：锈湖3D同人游戏；图标、名称和标签只写：锈湖 天堂岛。”我的理解：把名称、简介、图标和封面上所有带“灾 / 3D / 第一灾 · x灾”的字样去掉，只留“锈湖 天堂岛”。
**理解有歧义的地方**：用户说的“标签”我按“图标和封面上的副标题那一行”处理；后台的“场景标签”是平台固定的几个选项（休闲玩法等），不能写文字，保持“休闲玩法”没动。名称里的空格和去掉“：”是照用户原话写的。

## 做了什么

1. **图标 / 封面**：`dev/minitool/make_icon.py` 新增环境变量 `ICON_TITLE`、`ICON_SUB`（`ICON_SUB` 设成空串就不画副标题，标题下移居中），默认值不变。生成 `dev/minitool/icon-title-only.png`（512×512，场景图仍是 `dev/shots/red-x/icon_scene.png`，只写“锈湖 天堂岛”）。命令：`ICON_TITLE="锈湖 天堂岛" ICON_SUB="" python dev/minitool/make_icon.py dev/shots/red-x/icon_scene.png dev/minitool/icon-title-only.png`。封面用同一张图在后台裁成 3:4（裁剪框默认比图小一圈，标题左右只留了很小的边距）。
2. **撤回 V1.0.7**：V1.0.7（死→S）是前面刚提交的，审核中不能改信息，只能先“撤回”（提示“撤回后正在审核的最新版本将会被删除”），撤回后列表回到已发布的 V1.0.4。
3. **重新上传同一个 zip**（`dev/minitool/rusty-lake-minitool-ch12-s-20261019-release.zip`，SHA256 `ff55a530…8d46c5`，包内容与 V1.0.7 完全一样）→ 版本号自动 **V1.0.8**；名称改 `锈湖 天堂岛`（6/14），简介改 `锈湖3D同人游戏`（8/14），换图标和封面，权限 / 标签沿用；勾选《小工具发布安全规范》→“发布小工具”。
4. 结果：列表显示 **“锈湖 天堂岛”V1.0.8 审核中**；线上生效的仍是 V1.0.4。
