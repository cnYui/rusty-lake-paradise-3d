# 小工具 1.0.5 功能缺陷：修复与验证结果

## 结论与证据边界

当前源码存在确定可复现的打包回归：全屏补丁误删 `chapterOpen`，普通首页进入 `ui.menu.show()` 就报 `ReferenceError: chapterOpen is not defined`。程序在绑定开始按钮、创建新游戏 / 成就 / 设置入口之前停止，首页菜单未显示。

1.0.4 的实际发布 ZIP 不含新增的 `chapterOpen` 调用，已有相同的兼容垫片、旋转壳和音频输出文件，因此这次新增章节菜单逻辑与旧打包补丁的冲突可以解释旧包可用、当前新包失效的差异。

后台已实时确认 1.0.5 未通过、1.0.4 生效中。但本次没有拿到 1.0.5 的原始上传 ZIP 或审核端控制台堆栈，不能把当前源码的复现当作审核端已确认的唯一原因。

## 改动

- `dev/minitool/build.py`：禁用全屏时逐个替换 `fullscreenSupported()`、`enterFullscreen()`、`toggleFullscreen()`，不删除它们与物品栏之间的其它代码。每个函数必须恰好匹配一次，否则构建失败。
- `dev/minitool/test_minitool.py`：从无参数首页检查 `RLP.bootError`、菜单完整性、章节开放状态；加入真实触摸成就 / 设置、面板关闭、静音、重置确认及取消。出现失败检查时进程以非零状态退出。
- `AGENTS.md`：新增目标函数补丁边界和普通首页验证要求。
- 没有修改既有第二灾源码；没有覆盖历史 ZIP、dist 或上下文文档。
