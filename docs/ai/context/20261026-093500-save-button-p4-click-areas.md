# 暂停面板“保存进度”按钮 + 第四灾点击范围放大（2026-10-26）

## 起因
- 玩家反馈两件事：想在右上角设置里手动保存进度；第四灾（蝇灾）里兔子、鸟等小东西点不中。

## 保存进度
- `src/core/ui.js` 的 `openSettings`（右上角齿轮打开的“暂停”面板）新增“保存进度”按钮，所有章节共用。
- 游戏原本就会在状态变化后自动存档（`main.js` 的 `scheduleSave`）；按钮只是让玩家手动存一次并看到结果，面板下方的小字显示：
  - 上次保存时间（取存档里的 `savedAt`），点了之后变成“已保存：时间”；
  - 过场 / 谜题动画进行中（`ui.locked`）不存半截状态，提示“正在播放过场，结束后会自动保存”（自动存档本来就会等它结束）；
  - 存储写不进去（隐私模式等）提示“这里不能保存进度，关掉后会从头开始”。
- 验证：桌面 1280×720 和手机横屏 812×375 都能点；存档里能读到刚设的旗标；过场中不存；存储禁用时提示失败。

## 第四灾点击范围
- 原因：热点只对物件自己的网格做射线，兔洞是 1 cm 厚的贴地圆盘，鸟 7×14×25 cm，心脏 12 cm，漫游时站远一点、手机上都几乎点不中；陷阱旁的鸟本身没有进陷阱特写的热点。
- `src/chapters/plague4/world.js` 新增 `fatten(ctx, object, { min, pad, include })`：在物件下挂一个不可见的点击盒（每边至少 `min` 米、比实体多出 `pad`，按物件局部轴、只往上长高、底边贴实体），沿用公共的 `hotspots.makeProxy`，同一物件只挂一个。放大的物件：陷阱石板、兔洞（含洞口的兔子）、兔子、鸟、岸边的蟹、三颗心脏、胡萝卜、蜡烛、黑方块、猫头鹰上的宝石、结尾的 omen。
- `story.js` 新增 `bird_zoom`：漫游时直接点陷阱旁的鸟也进陷阱特写（原来只有石板能点）。
- 点击盒重叠时的让位（`world.js` 里的 `rabbit_zoom / trap_zoom / crab_zoom` 加了 `when`）：猎物被吃掉、心脏摆出来后，洞口 / 石板让出点击给心脏；蟹盘通关（第 3 轮完成）后蟹盘特写没用了，让出点击给岸边的蟹。
- 度量（1280×720，每 6 px 扫整张画面，能点中该热点的像素包围盒 w×h，最终尺寸，之前 → 之后）：
  - 漫游：兔洞 78×36 → 252×216；兔子心脏 24×24 → 90×120；鸟（`bird_zoom`）18×30 → 204×234；鸟心脏 30×30 → 144×174；岸边蟹 180×144 → 312×264；蟹心脏 24×24 → 240×216；胡萝卜 30×72 → 114×156；蜡烛 84×90 → 186×150。
  - 固定镜头：黑方块 24×18 → 102×90；宝石 36×30 → 126×138；特写里的兔子 / 鸟 / 蟹和三颗心脏从 54–324 px 变到 234–558 px。
  - 陷阱石板（180×138）没变。扫描脚本不入库（临时文件）。
- 没动：蟹盘格子（34 cm）、猫头鹰嘴和翅膀、窗锁滑片和槽位（相邻 10 cm，放大会互相盖住）、石板上的大物件。
