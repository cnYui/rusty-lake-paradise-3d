# 第二灾完整实现与精细建模计划

## 实现范围

- 完成人物 Gerard、Ida、Caroline、搅锅的 Margaret、吃青蛙的 David。复用角色骨架、皮肤和布料工具，新增服装结构、脸部纹理、手部姿态及道具动作。
- 完成睡莲棋盘、配对蛙卵盆、厨房锅和桌箱、回忆框、神殿凳子、转盘柜和木柴。结构与视频形状、颜色、材质细节相符，优先合并静态网格。
- 补齐四段章节逻辑和真实公开交互的 walkthrough，结尾断言 `plague2_complete`，通过后开放菜单。
- 蛙卵采用真实配对规则：孪生为 7/9、1/12、4/10、3/11、2/8、5/6；错配复位并锁定约一秒；pending 和掩码均存档。沉下不到半秒的短暂动画差异不作为独立玩法规则，统一恢复保证存档确定性。
- 睡莲保留五关，支持所有合法路线、走错重试。保存关次与关内位置，关闭再打开不丢失玩家操作。
- 转盘中圈每次 45°、外圈每次 30°；初始 3/8，解开时都为 0。Ida 五个乐句按视频顺序变色。
- 四只青蛙、柴火与蜡烛构成煮汤前置；给 Gerard 汤和碗才能取得钥匙；回忆后取黑方块，送入神殿吊架完成。
- `sync()` 幂等且双向恢复，重开新游戏不残留模型状态、动画、下降量或热点。必要时只重建本章不可逆对象。
