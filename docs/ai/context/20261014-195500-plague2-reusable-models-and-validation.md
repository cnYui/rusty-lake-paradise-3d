# 第二灾人物复用与实操验收

用户要求人物更精细，并在后续章节复用。David 与 Margaret 的身体、面部系统、手指骨架和布料沿用公共 `CHAR_KIT`；Gerard 沿用家族回忆的真人身体，解除面具后增加帽子、立体胡须及进食动作。Ida 与 Caroline 共用 `buildWoman` 骨架、裙装放样和面部绘制，发型、配色、笛子和婴儿为组合部件。所有工厂可由后续章节直接调用，不重复构建身体代码。

本次参考仍为本地第二灾视频。第一轮模型预览与场景截图已检查；补做草叶倾角、细水纹、连续砖圈、Ida 弧形双翻领和 Gerard 立体胡须。第一轮场景截图偏暗源于开发跳转的入场动画尚未结束，显式等待 `RLP.start()` 与 `RLP.idle()` 后颜色正常，未改公共灯光。

David 给腰带后进入石头特写，避免青蛙处于人像镜头之外。吊架热点使用主体而不包含四米长绳索。第二灾圣水盆使用公共模型实例的灰色液体参数，不沿用第一灾的脉动血色。结尾依据逐段旗标继续，已插入方块的存档可点吊架或画面继续，无须再次取得方块。

新增规则验收 `dev/test_plague2.mjs` 与浏览器实操 `dev/test_plague2_browser.py`。后者等待画布 CSS 动画稳定后做射线采样，鼠标和触屏真实输入共用公开热点；导航传送用于测试定位，谜题点击和物品使用不用 `RLP.click()` 代替。最终结果另建记录，尚未验收通过前不开放菜单。
