# 233 乐园版：提示内容的设计

用户的要求：提示用纯文字；检测当前关卡所有谜题哪些做了、哪些没做；谜题有前后顺序，只提示用户没做的事。

## 现状（读代码得到的）

- 每章的状态都在 `state.flags` 和 `state.inventory` 里（AGENTS.md 的规定，读档靠 `sync()` 恢复），所以“谜题做没做”可以只看 `state.flag(key)` 和 `state.has(item)`，读档后结果一样。
- 用掉的物品会从物品栏里消失（例如鱼竿钓到虾后 `rod` 就没了），所以**不能只看物品栏判断完成**，要用旗标。
- 每章已有的旗标：第一灾 50 个、第二灾 42 个、第三灾 66 个、第四灾 35 个、第五灾 39 个。
- 各章已有 `walkthrough`（自动通关的点击脚本），但它是一条线性的点击序列，没有“谁依赖谁”，不能直接拿来当提示数据；可以拿来核对提示表有没有漏步骤。
- 提示文字的显示：现成的 `ui.hint()` 是顶部白字，3.6 秒就消失；暂停面板（`openSettings`）是应用内面板，适合放“看完广告才拿到”的内容。

## 数据：每章一张任务表 `src/chapters/plagueN/hints.js`

```js
export const HINTS = [
  { id: 'bamboo', after: ['box'], done: (s) => s.flag('bamboo_cut'),
    text: '沙滩左边有一丛竹子，用砍刀把它砍断。' },
  { id: 'rod', after: ['bamboo'], done: (s) => s.flag('rod') || s.flag('shrimp_caught'),
    text: '用竹竿、线、钩子和虫子合成一根鱼竿，在物品栏里把它们两两合在一起。' },
  ...
];
```

- `done(s)`：只读 flags / inventory 的纯函数。
- `after`：前置任务 id（没完成前置就不提示）。
- 数组顺序 = 同时可做时的优先级；可选 `zone`，用来优先提示玩家所在区域里的任务。
- 粒度：一个“里程碑”一条（拿到物品、开一个机关、完成一个谜题），不是一次点击一条；每章约 15–25 条，五章共约 80–100 条。

## 算法：`src/core/hints.js`（纯函数，不依赖 DOM）

1. 可提示 = 没做完 且 所有前置都做完的任务。
2. 章节已通关 → 提示“这一章已经通关了”，不放广告。
3. 可提示不止一条时：先取玩家当前区域的，再按表里顺序取第一条。
4. 可提示为空但章节没通关 → 说明表漏了前置或旗标，兜底文案并在控制台报警（测试会抓到）。

## 展示

- 纯文字，应用内面板（和暂停面板同款）：标题“提示”，1–2 句话，按钮“知道了”。不用顶部字幕条，3 秒就消失，广告白看了。
- 文案写“去哪 + 做什么”，用游戏里的物品名（从 items 定义取，保证一致）；谜题内部（蛙卵配对、睡莲、寄居蟹、菜地、连线）只说去哪个特写做什么，不报答案。

## 点灯泡的流程

点灯泡 → 先算出提示（没有可提示的就不放广告）→ 游戏内确认框“观看一段广告后获得提示”[观看广告][取消] → `showRewardVideoAd()` → 只有 `status === 4` 才显示提示面板；关闭 / 跳过 / 失败 / 超时都不给提示，只提示“广告没有看完，没有获得提示”。

## 测试

- node：空状态下可提示非空；把 `walkthrough` 跑完的状态代进去，所有任务 `done` 为真；任意状态下被提示的任务其前置都已完成。
- 浏览器：`RLP.autoplay()` 每一步后取一次提示，未通关时必须非空；通关后全部 `done`；读档后提示和读档前一致。

## 用户拍板（2026-10-25）

- 广告可以一直看，**看一次显示一条**（当前最该做的那一条）；同一条没做完再点灯泡会再放一次广告，不做“免广告重显”。
- 提示不给谜题答案，只说去哪、做什么（沿用建议）。
- 实现交给 `/dsh-dispatch`：核心引擎和界面由主会话写，五章的 `hints.js` 和广告封装 `src/core/rewardad.js` 由 dsh 工人写，主会话审 diff 后合并并跑测试。

## 实现落点

- `src/core/hints.js`：纯函数 `nextHint / pendingHints / isDone`。
- `src/core/rewardad.js`：官方 `RewardAdService.ts`（参考副本在 `dev/common/leyuan-ref/`）的 JS 版，无 DOM；本机（localhost）或乐园预览（`__PM_BUILD_PROFILE__ === 'fast'`）且没有 `MetaH5Ad` 时进入模拟模式，由调用方传 `pickMock`；真机乐园永不模拟。
- `src/core/hintflow.js`：灯泡的流程（算提示 → 确认 → 广告 → 显示）。
- `src/core/ui.js`：`ui.dialog()` 通用对话框（Esc 点带 `esc` 的按钮）、`setHintButton()`。
- `src/main.js`：`initHints()`、`RLP.hints.next() / tasks()`（测试用）。
- 每章 `src/chapters/plagueN/hints.js` 导出 `HINTS`，章节对象的 `hints` 字段指向它。
- 测试：`node --test dev/common/test_hints.mjs`（结构、旗标存在、广告归一化），`python dev/common/test_hints_browser.py`（五章逐步自动通关 + 灯泡流程）。
