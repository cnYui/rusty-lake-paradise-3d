## 1. 石塔（stone tower 3d model.glb）

- 现状：岛上本来就有一座程序化三层石塔（`buildings.js` 的 `buildTower`，14.6 m，西岸 `P.tower`），但森林树冠约 25 m，从南面远景完全被挡住，看不到。
- 做法：和牛一样做成静态网格（`dev/common/models/tower_export.py`，6 万面，贴图 2048²），高 **38 m**（原作图里塔明显高出树冠）、底面半径约 6.8 m，`src/art/tower_model.js` 建 `tower` 组，`buildings.js` 的 `buildTower()` 有模型就用模型、没有回退程序化塔。模型在世界建好之前预加载（`main.js` 在 `buildWorld` 前 `preloadModels(['tower'])`）。
- 位置：`P.tower` 从 (-30, 18) 挪到 (-24, 14)（参考图里塔在天堂门左侧约 22 个单位、隐在林中、塔顶高出树冠），`height: 38, radius: 6.9`；岩石平台（`island.js` 的塔山）平台半径 4.4 → 7.5、缓降到 15 m，山脚的大石头环放大一圈，森林树不再长进塔周围 12.5 m 内，碰撞圈（`world.js`）半径 3.0 → `P.tower.radius`。**没有扩大岛的轮廓**：塔离西岸（x ≈ -38）还有 7 m，放得下。
- 贴图配色：AI 烘出来的贴图偏写实（照片感的棕灰砖、棕色木门、很多噪点）。`dev/common/models/tower_recolor.py` 做调色：中值滤波抹掉照片噪点 → 按亮度重映射到一条暖灰石头色带（墨黑窗洞 `#2b2724`、灰砂浆 `#6f6a60`、暖灰石面 `#a49e8c`、浅色檐线 `#d9d0b6`，和岛上其他石头同一套）→ 亮度梯度大的地方（砖缝、窗框、檐口）压暗一点当墨线。门和窗都变成墨黑，整体接近参考图里米灰的手绘石塔。

## 3. 摆直了再量比例（用户纠正）

用户指出：所有 AI 模型都是“大字型”（手臂平伸、腿叉开），要绑好骨骼、把腿摆直、再量比例。流水线本来就是这么做的（`rig_export.py`：`delta0` = 腿摆直后身体抬高的量，缩放 `s = H / (头骨顶 + delta0)`，休息姿势下头骨顶 = 表里身高），但有三类没做到，这次补上：

- **裙装 / 长袍人物（Margaret、鸽子）**：之前腿藏在裙子里按竖直量，没有把腿长算进去。现在腿长按“髋 → 踝”的真实距离（大字型摆直后的长度）平分，缩放按摆直后重算：Margaret 缩放 1.60 → 1.48（小 8%）、鸽子 1.70 → 1.62；绑定时腿仍竖直、膝盖放在“摆直后的位置”，所以裙摆下半截不会被拉离地面，鞋子靠脚关节整体平移到身体下面（脚的归属改成“脚关节附近的顶点”，之前阈值单位用错，缩放前后的坐标混了）。
- **鹿**：腿和靴子是可见的，改成普通人物（腿骨绑定时就倾斜，休息姿势下腿竖直、靴子不再歪着），缩放 2.40 → 2.19。
- **苍蝇人**：之前骨盆按绑定姿势的高度，腿摆直后脚会陷进地里 0.17 m。现在同样用 `delta0`，骨盆抬高 0.28 m，缩放 3.40 → 2.89（头骨顶 1.9 不变）；跪下的下降量也改成由腿长算（`fly_model.js`）。
- 其余（David / Gerard / Nicholas / 少年 Jakob / 兔 / 野猪 / Ida）绑定时手臂和腿就是按大字型绑、休息姿势摆直，本来就对。
- 验证（浏览器里把每个 rig 的 pose 全部清零后用 `getVertexPosition` 取蒙皮后的顶点）：脚底 y 都在 ±0.004 以内，头骨顶（头关节 y + 头半高）= 比例表身高：David 1.78、Gerard 1.84、Nicholas 1.88、Margaret 1.56、Ida 1.58、少年 Jakob 1.30、兔 1.78、野猪 1.84、鸽子 1.56、鹿 1.88。

## 4. 顺手修的 bug

- `rig_export.py` 里裙子 / 脚的权重阈值用了“缩放前”的单位（网格已经缩放过），导致裙子区域、鞋的范围都错了；改用缩放后的尺度 `Ts = T × s`，并且垂在髋以下的手臂（A 字姿势，Ida）不算裙子。
- 摆姿势后蒙皮包围盒要重算：`attachModel` 在 `rig._after` 里把网格的 `boundingBox` 置空（`Box3.setFromObject` 才是当前姿势）。
