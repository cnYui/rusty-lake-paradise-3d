## 操作方法（以后复用）

- 浏览器：Chrome 插件（不是内置浏览器），小红书创作中心笔记管理页点笔记缩略图打开笔记（直接用 `/explore/<id>` 地址会 404，需要带 `xsec_token`，只能从创作中心点进去）。
- 评论是页内弹层，滚动容器 `.note-scroller`，顶层评论 `.parent-comment`，楼中楼 `.comment-item-sub`，回复按钮 `.reply.icon-container`，展开楼中楼 `.show-more`（文字“展开 N 条回复”）。
- 回复流程：点回复 → 输入框顶部显示“回复 XXX：原评论”确认目标 → 输入文字 → 点“发送”（视口 1348×803 时在约 (1035,742) 或 (1131,742)，位置随弹层宽度变化，用 `getBoundingClientRect` 实测最稳）。
- 删除自己的评论：评论右侧“⋯”→“删除评论”→ 页内确认框“确定”。
- 批量发送时每条之间等 1.8 秒，并在每批结束后用脚本核对每个人的“踢踢”条数；**发之前必须先统计“已被通知的人”，包括顶层与楼中楼、同一个人的多处评论，避免重复。**
