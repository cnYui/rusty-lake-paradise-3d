# 全岛栅栏、小屋两侧围墙、记忆场景一家人重做

## 用户反馈

1. 记忆场景（拔完钉子、点开棺材后看到的戴动物面具的一家人）建模太粗，需要精细一些。
2. 一开始整个岛需要用栅栏围起来，否则可以从旁边绕过去。
3. 最后上锁的房子（去湖区的小屋）那边也要加围墙，防止绕过去。

## 原因

- 天堂门栅栏只从 x = -24 修到 24，岛在这一线实际宽到 x ≈ -27.3（西岸）和 25.6（东岸），漫游还能再往浅水走 1.25 m。
  门没开之前有一条看不见的线（`z < 40.6` 都不能去）挡着，所以走不进去，但画面上栅栏两头明显有缺口，走过去会被看不见的墙挡住。
- 小屋同样只靠一条看不见的线（`z < -13.2`）挡住整个北面。小屋本身只有 5 m 宽，两边是开阔的林子，看起来完全可以从旁边绕过去。
- 记忆场景的五个人是早期的占位模型：圆柱身体、球形肩膀、面具是几个球和圆锥拼的（女孩的鸟头面具从正面看就是一张空白的脸），
  鹿的举方块姿势像在打电话，场景里也没有原作里摆在一家人面前的棺材，`memory.family*` 锚点的朝向也没用上。

## 修改

### 栅栏和围墙

- `src/art/layout.js`
  - `PALISADE` 两端改到 x = -30.5 / 28.6，伸进湖里约 3 m。
  - 新增 `SHED_FENCE`（小屋两侧木板围墙的三段折线）和 `shedLineZ(x)`（整条分界线在 x 处的 z）：
    小屋西墙 → 两棵大树 → 石屋东墙；石屋西墙 → 一串树干 → 西岸湖里；小屋东墙 → 荆棘丛后面 → 一串树干 → 东岸湖里。
    石屋本身是墙的一部分；折线顶点多数落在树干中心，木板像钉在树上。
- `src/art/island.js`
  - 栅栏伸进湖里的木桩插在湖底，顶端按岸上地面算，和岸上一样高。
  - 新增 `buildShedFence()`：和小屋前墙同样的灰木板（宽约 0.27 m，高 2.9 m，高低略有参差），北面（湖区一侧）两道横档，
    约 2.6 m 一根方立柱；树干里面的木板省掉。两个合并网格（木板、框架），`named.shed_fence`。
- `src/art/world.js`：`colliders.segments` 加上围墙每一段（半宽 0.14）；栅栏线段跟着 `PALISADE` 自动加长。
- `src/chapters/plague1/forest.js`：小屋门禁改成沿围墙同一条线判断 `z < shedLineZ(x) - 0.2`（围墙是实体碰撞，门禁主要挡小屋门洞）。
- 第二灾沿用同一个岛：它按位置和半宽删除第一灾的几个道具碰撞，不影响新增的围墙线段；小屋在第二灾只剩门框，门洞照样能走。

## 验证

- 新增真实键盘漫游测试 51/51（按住 W + Shift 往墙上走）：
  - 天堂门没开：海滩上 9 个位置往北走、从两头斜着往湖里走，全部停在栅栏前（z ≥ 40.6）。
  - 天堂门开了：从门洞走进森林；栅栏两头仍然绕不过去。
  - 小屋没开：围墙全线 19 个位置往北走、5 条斜线冲向墙和树干的接缝，全部停在墙前；走到小屋门口停在门板前（和改动前一样）。
  - 小屋开了：从小屋门洞一直走到灵魂小径；两侧围墙仍然挡着，从湖区一侧往南走也被挡住。
- `RLP.autoplay()` 91/91；电脑端输入 26/26 与 10/10、房子室内 28/28、触屏 27/27、棺材钉子鼠标 13/13 与触屏 13/13；无页面错误。
- 渲染开销（SwiftShader，含描边）：记忆场景 308 次绘制、21 万三角形（预算 400 次以内）；五个角色各 24–36 个网格、1.9–2.5 万三角形。
  围墙只多两个合并网格。
- 截图检查：海滩两端栅栏伸进血湖、总览里栅栏横跨整个岛、猫头鹰和石屋后面是连着石屋的木板围墙、小屋右侧围墙在荆棘丛后面；
  记忆场景五个角色从正面、侧面和游戏镜头都检查过，构图对照原作 f_0703。
