依据本地 `dev/ref/P02_第二灾-蛙灾_BV1bo4y1y7fm.mp4` 和抽帧核对人物、道具、谜题及动作。参考视频和抽帧不提交、不部署。设计与实施背景见本轮 191200 和 195500 两份记录。

David、Margaret、Gerard 组合现有家族人物的真人身体、面部、手指和骨架；Ida 与 Caroline 共用女性模型工厂。人物变化通过发型、衣物、道具和动作组合，后续章节可复用工厂。精修包括 Gerard 灰帽与立体胡须、Ida 分层红发及弧形翻领、David 腰带和扣件、Margaret 双手搅拌、Caroline 包头帽与婴儿包布。

道具补齐睡莲缺口和叶脉、蛙卵水盆与水纹、陶锅和砖灶、木腿桌凳、开盖木箱、转盘木柜、笛子与吊架。第二灾圣水盆仅调整本章实例，不影响第一灾血水显示。带贴图的合并几何保留 UV。经过三轮实际引擎画面检查，最终截图位于 `dev/shots/p2/verification/final-*.png`。

## 主线与操作

1. 在蛙卵盆按形状配对，完成五关睡莲跳跃；取得神殿柜内的蛙笛，交给 Ida 吹奏；给 David 系腰带。四条支线各得到一只青蛙。
2. 收集碗、蜡烛、木柴，把四只青蛙放进厨房锅内，加柴点火，用碗盛汤。
3. 给 Gerard 喝汤，再交空碗接住呕吐物，从碗内取钥匙。
4. 钥匙打开厨房木箱，观看母亲抱婴回忆，再取黑方块。
5. 把黑方块放入神殿吊架，完成驱蛙仪式和章节结尾。

电脑使用 WASD 或方向键走动，鼠标靠近画布边缘转视角，点击场景互动。数字键选中物品后点击目标使用，特写按 S 或下方向键返回。触屏按横屏设计，左侧拖动为摇杆，其它位置拖动转视角，轻点互动，物品栏直接点选。
