#### 谜题规则（纯规则写在 `src/chapters/plague6/rules.js`，不 import three）

1. **疹子（静脉连线）**：胸口 15 颗疹子，颜色只有橙 / 绿 / 灰三种，疹子之间画着细红“静脉”（一张图的边）。规则：第一颗必须是橙色；之后每一颗必须沿静脉和上一颗相连、颜色按 **橙 → 绿 → 灰 → 橙 …** 轮换；点错（不相连、颜色不对、点已破的）就全部复原。15 颗全部挑破 → 出现 ×。接受任何满足规则的顺序；`rules.js` 要导出求解器（DFS），测试断言至少有一个解、给出的示例解合法、随便点错会复原。
2. **四体液与配药**：医生图例 `HUMOR_DIR = { blood: 9, tears: 10.5, snot: 12, saliva: 1.5 }`（杖头指向的钟点方向）。CURE 书 6 行从下往上画箭头，对应配方 `CURE = ['tears', 'snot', 'saliva', 'snot', 'tears', 'blood']`（从瓶底往上倒的顺序）。倒错一次量瓶倒空重来；倒满 6 层 → 药。
3. **牙齿**：上排 8 颗牙形状固定（4 种缺口形状），下排 8 颗是同一组形状的一个打乱排列；先点一颗下牙再点另一颗下牙 → 交换；每一列上下形状一致（咬合）即完成。初始排列写在 `rules.js`，接受任何交换顺序。完成后下排第 5 颗（下标 4）显示“×”、上排第 8 颗（下标 7）显示“∶”。
4. **落地钟**：×针、∶针各点一下前进 1 小时（12 个位置）；初始 × 在 XII、∶ 在 III；×=5 且 ∶=8 时钟面打开。
5. **字母箱**：4 个转盘，每个在 `B O A R L T K W` 八个字母里循环，拨成 `BOAR` 打开。

#### 谜题规则（`src/chapters/plague7/rules.js`，不 import three）

1. **冰块（立冰压平冰）**：格子上有“立着的冰块 S”和“平躺的冰块 L”。一步 = 选一块 S，再点一块与它上下左右相邻的 L：S 消失，L 变成“压实 F”（之后不能再动、也不能再被压）。场上没有 L 就过关；走进死局（还有 L 但没有相邻的 S）可以点重置。3 关，`S` 数 ≥ `L` 数；`rules.js` 导出求解器（二分图匹配或回溯），测试断言每关有解、示例解合法、至少一关存在会走进死局的错误第一步。
2. **滑冰（冰面滑行）**：格子冰面（例如 7×5），树桩是障碍。Caroline 每次朝上下左右之一滑出去，一直滑到撞上树桩或冰面边缘才停（点她那一行 / 列上的任意一格表示方向）。停在目标裂纹格上就过关，3 关，第 3 关的裂纹下冻着胡萝卜。`rules.js` 导出 `slide(level, pos, dir)` 和 BFS 求解器，测试断言每关可解、最少步数分别 ≥ 2 / ≥ 3 / ≥ 4。
3. **冰淇淋**：牛角敲冰锥（冰锥计数旗标）→ 桶里有冰 → 点桶倒扣成雪球 → 草莓或开心果用在雪球上 → 对应口味的冰淇淋。先草莓后开心果（Gerard 第一次只要草莓，吃完气泡换成绿色的开心果）。
4. **雪人**：5 个部件（围巾、帽子、树枝、小石子、胡萝卜）顺序随意，全装上后过场。
5. **雪景球机器**：3 个孔，任意顺序放入 3 颗钻石。
