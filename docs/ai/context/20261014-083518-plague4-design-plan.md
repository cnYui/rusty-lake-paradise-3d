## 实现决策

1. 新建 `src/chapters/plague4/`，用 world / puzzles / story / items / text / index 分开布景、纯规则、交互和编排。新模型集中 `src/art/props_flies.js`，直接使用已有材质、模型工厂和角色；不依赖未完工的第二章模块。
2. 复用全岛环境、`views.go()` 的室内与特写切换、房间漫游范围和碰撞。移除第四章未摆放的第一灾物品碰撞，两道门的状态由第四章 flags 决定。天堂门开局开放，小屋石门必须先有宝石，不能从漫游绕过。
3. 寄居蟹保留三轮、定向贝壳、海胆碰撞和出口；将二维拖动改为双端统一的“点贝壳、点格位、点寄居蟹出发”，不新增拖动视角或鼠标物品栏操作。只改变章节谜题交互，规则函数与 Three.js 无关。
4. 所有进度进入 state flags；库存道具只通过现有 give/take/replace；`sync()` 能双向恢复初始、中间和通关模型状态，不能只恢复已解锁状态。自动流程走玩家公开热点，不直接写通关 flags。
5. 书本用原创程序化图文表达视频中的线索，窗锁保留四个可调整纹章和确认操作；场景、书本、谜题提示统一中文。
6. 结尾完整衔接黑方块、金色容器、圣水盆和下一灾画面；第四章验证完成后开放菜单，不公开未完成的第二、三章。
