# 原作近景轮廓修正计划

原有 `focus/` 多为场景远景，不能充分支持道具轮廓判断。本轮补抽 6 秒间隔联系图，并定位第六灾 01:01 牛头骨、01:49 钟面，第九灾 05:09 研磨机的原始分辨率特写。新增参考仍只在工作区 `.scratch/paradise-original-video-BV1bo4y1y7fm/`。

牛头骨改为尖长、收窄的鼻骨和渐细弯角，避免两颗椭球组成的动物脸。落地钟按原作补拱冠、凹槽边框和曲线雕花，保留钟面铰链、指针和发条心。研磨机改为方口梯形料斗、收腰立柱、阶梯底座和出料凹格，移除缺乏参考依据的侧面磨盘；现有侧摇柄作为 3D 交互结构保留，增加原作正面连杆联动。

状态探针发现新加的雪景球环和雪粒直接挂在机器根节点，取走球后仍显示。把球体细节挂回球体节点，使现有 `ball` 状态统一控制其可见性。

保持热点代理、方法和存档契约；本轮只改美术。完成后重拍近景、跑构造与双向状态探针、规则测试，并在实际章节镜头中检查变更轮廓和点击可达性。
