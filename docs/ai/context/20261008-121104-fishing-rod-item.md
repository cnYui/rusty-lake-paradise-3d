# 鱼竿合成后物品栏图标消失

## 问题

用户在线上（手机触屏）反馈：合成鱼竿之后，鱼竿图标从物品栏消失了。

## 原因

原来的三条配方只把鱼竿记成 flag（`rod` = line / hook / worm），最后一步“木棍 + 虫子”把木棍和虫子都从物品栏拿走，并没有生成鱼竿物品；钓虾则是 `rod === 'worm'` 时直接点海滩上的一块隐形区域（位于沙滩上，不在水里）。项目里也没有鱼竿模型。

## 修改

- `src/art/props_beach.js`：新增 `makeFishingRod({ hook, worm })` 和三个工厂 `rod_line` / `rod_hook` / `rod`。竹竿斜放、竿尖在左上（避开物品栏右下角的键位标记），鱼线从竿尖垂下；线尾依次是小线圈 / 鱼钩 / 挂着虫子的鱼钩。鱼钩放大 4 倍、虫子放大 5.5 倍，图标里三个阶段能一眼分清。
- `src/chapters/plague1/items.js`：新增物品“系着线的竹竿”“鱼竿”“挂好鱼饵的鱼竿”。
- `src/chapters/plague1/beach.js`：
  - 配方改为逐步升级：木棍 + 线 → `rod_line`，+ 鱼钩 → `rod_hook`，+ 虫子 → `rod`。用 `replace` 留在原来木棍的格子里，用掉的材料拿走，顶部显示新物品名；挂好鱼饵后有一句内心独白“也许能在湖边钓点什么。”。顺序不对（例如没挂钩先加虫子）不会合成。
  - 钓虾热点 `fish` 改为盖住海滩前整片浅水的隐形区域，只在持有鱼竿类物品、还没钓到虾时可点：选中挂饵鱼竿点湖面 → 水花音效、点击处出现涟漪、收线音效，鱼竿用掉，虾从水里飞进物品栏；用没挂钩 / 没挂饵的鱼竿点水会提示缺什么。
  - walkthrough 改为三步升级合成，并新增“拿到鱼竿 / 拿到虾 / 鱼竿用掉”三个检查（共 80 步）。
- `src/core/hotspots.js`、`src/core/context.js`：热点处理函数可以通过 `ctx.hitPoint` 拿到这次点击在世界里的位置（测试直接调用 `click()` 时为 null），用于在点中的水面放涟漪。
- `src/chapters/plague1/text.js`、`README.md`：新增文案，更新流程说明与步数。

## 验证

- 真实键盘 / 鼠标（10 项全部通过）：数字键合成三步、物品始终留在原格子；没挂钩先加虫子不合成；两件物品按任意顺序都能合成；鱼竿图标可见；面向湖面选中鱼竿点水钓到虾、鱼竿用掉；之后湖面不再可点；无报错。
