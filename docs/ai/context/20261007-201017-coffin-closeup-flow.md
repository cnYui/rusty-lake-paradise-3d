# 棺材钉子近景流程修复

## 问题

血池镜头只能直接看到棺材的一部分钉子，另外几枚需要棺材近景才能操作。原流程在棺材升起后没有进入近景的点击路径，自动 walkthrough 直接调用热点 API，掩盖了真实鼠标无法完成六钉的问题。

## 修改

- `coffin` 热点同时注册在 `blood_pool` 和 `coffin` 视图。
- 棺材升起后，玩家在血池再次点击棺材进入 `coffin` 近景；近景中六枚钉子保持逐个点击逻辑。
- walkthrough 在升起棺材后增加一次棺材近景点击，再操作六枚钉子。

## 验证

- `coffin` 近景的真实射线网格扫描命中 `coffin_nail_1` 到 `coffin_nail_6` 全部六个热点。
- 修改后重新运行完整 `RLP.autoplay()`，应以 `plague1_complete` 结束。
