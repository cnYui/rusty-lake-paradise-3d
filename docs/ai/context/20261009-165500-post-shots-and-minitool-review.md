# 图文截图与小红书小工具审核状态

## 用户要求

把宣传片截几张图，发一条新的图文帖到抖音和小红书：
- 小红书那条挂载“锈湖”小工具，文案「《锈湖：天堂岛第一灾》3D版本上架小红书小工具！点击即玩」；
- 抖音那条把“小红书”改成“小某书”，话题（hashtag）多加一些相关的。

## 做法（截图）

- 从 `dev/promo/锈湖天堂岛3D_宣传片_30s.mp4`（1920×1080，画质最高的那版）抽帧，避开镜头之间溶解转场的重影帧。
- 实测 `select=eq(n,…)` 按帧号取出来的帧，和 `-ss` 按时间取的对不上（帧号不等于时间 × 30，可能是视频时间戳有偏移），所以最后都按时间 `-ss` 取。
- 存放：`dev/promo/post_shots/`（JPEG，每张 130–330 KB）：
  01 岛屿标题“第一灾 血灾”、02 血色的湖和船（7.6 s）、03 玛格丽特和山羊、04 艾兰德全家福（14.5 s）、
  05 父亲举酒杯喝血、06 湖边黑衣人（20.2 s）、07 棺材漂在血湖上（21.6 s）、08 动物头一家人（26.4 s）、09 神殿（27.2 s）、
  10 片尾卡（上面写着“小红书小工具”，只给小红书用，抖音那组不放）。

## 发现：小工具审核未通过

小红书创作者中心 → Builder hub → 小工具（`https://creator.xiaohongshu.com/new/red-app`）：

- 「锈湖：天堂岛3D」V1.0.0 状态 **未通过**，原因：“小工具功能缺陷，可能是页面按钮无法点击，重点排查页面功能完整性”。
- 页面写明：审核通过后，发笔记时才能通过「发布页 → 添加组件 → 小工具」挂载。
- 同一列表里“银魂像素剧场”已发布（537 人使用）。

结论：现在小红书那条挂不上小工具，帖子里“已上架”的说法与事实不符。**这一轮没有发布任何帖子**，只读了页面和做了截图，等用户决定。

## 可能的原因（都没验证）

- 提交审核的包（`dev/minitool/rusty-lake-minitool.zip`，11:25 打包，之后没改过）只在模拟的容器 CSP + CDP 触摸下测过，没有真机测（上一份记录已写明）。
- 审核环境可能跑不动 / 不支持 WebGL，或旋转 90° 后触摸坐标在真机上对不上，表现都是“按钮点不了”。
