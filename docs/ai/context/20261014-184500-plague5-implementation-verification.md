# 第五灾实现与验证记录

## 参考资料

- 第三至第十灾参考视频均位于 `dev/ref/`，来源为 B 站 `BV1bo4y1y7fm`。
- 第五灾使用 `dev/ref/P05_第五灾-疫灾_BV1bo4y1y7fm.mp4`，时长约 21:06；抽帧在 `dev/ref/plague5/`，只作本地参考。

## 实现

- 新增第五灾专属程序化模型 `src/art/props_p5.js`，工厂统一使用 `p5_` 前缀。
- `src/chapters/plague5/world.js` 补齐病牛、菜地与连线入口、可走动厨房、饭桌、厕所、回忆和神殿，临时题面区域自带灯光。
- `src/chapters/plague5/puzzles.js` 将斑点配对、三轮菜地、五轮连线、牛奶奶酪、食材加工、锅、汉堡层数、Gerard、圆盘、黑方块和神殿动画串成完整状态链。
- 所有中途状态写入 flags；模型由 `sync()` 重建或恢复。第五章入口仍保留 `wip: true`，无参数首页不会显示为可选章，`?wip=1` 才能从菜单进入。
- 新增 `dev/test_plague5.mjs` 规则测试和 `dev/test_plague5_browser.py` 浏览器验收脚本。

## 验证结果

- `node --test dev/test_plague5.mjs`：6 项通过，覆盖越界、重叠、行列计数、连线撤销、度数上限和断图。
- `python dev/test_plague5_browser.py`：通过自动通关 188 步；真实鼠标与数字键 165 次；触屏配对、菜地、连线和物品栏；错误汉堡顺序不消耗食材；菜地、连线、汉堡和神殿中途读档；新游戏复位；室内碰撞、特写返回原位、神殿和厕所门禁；普通菜单和 `?wip=1` 菜单入口；无页面错误或失败请求。
- `dev/shots/plague5/` 保留病牛、斑点、菜地、连线、厨房、饭桌、厕所、回忆、神殿画作和触屏截图，目录已被 `.gitignore` 排除。
