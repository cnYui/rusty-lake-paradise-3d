## 最终实现与适配

第四章已开放菜单，入口为 `src/chapters/plague4/index.js`，不依赖第二、三章进度。主线包含蛹孵化、厨房蜡烛与胡萝卜、地洞取树枝和虫子、三轮寄居蟹、苍蝇人依次捕食蟹／兔／鸟、三颗心喂猫头鹰取得宝石、书本与四枚窗锁、父亲被带走、父子回忆、黑方块和神殿结尾；蜡烛照见地洞红心纸牌为可选成就。

- 专属模型集中在 `src/art/props_flies.js`，由基础几何和画布贴图生成，复用公共角色、材质、机关及动画；第四章直接导入自己的模型文件。
- `world.js` 定义布景、机位、碰撞和恢复；`story.js` 注册公开热点；`puzzles.js` 保留与画面无关的规则；`items.js`、`text.js`、`walkthrough.js` 分别承载物品、中文文本和公开交互流程。
- 寄居蟹保留三轮定向贝壳、海胆、圆形终点及失败重试。将原视频拖动改成“点贝壳、点空格、点寄居蟹出发”，鼠标和触屏使用相同规则。按路径逐格模拟，识别海胆、出界和循环，不以固定摆法判定成功。
- 窗锁四个独立刻度从左到右为 `1、3、8、10`，书本提供纹章顺序和数值线索。
- **门禁以本记录为准**：天堂门和木小屋开局开放；绿色宝石打开的是神殿入口的石门。设计初稿将石门写在木小屋，会把湖边寄居蟹与宝石互相设为前置；最终实现采用神殿门禁避免循环依赖。神殿内部通过条件入口进入，室外建筑保持实体碰撞。
- 章节状态使用 `p4_*` flags 和公共物品栏，完成标志为 `plague4_complete`。同步支持新游戏、部分进度和完成状态，恢复父亲／苍蝇位置、窗户、贝壳、容器、绳子和水面。鸟在捕鸟盘支好并放虫子后出现；胡萝卜在箱盖打开后出现。
- 保留公共的鼠标靠边转向、数字键物品栏和触屏输入。室内漫游受墙体与家具约束；出门恢复室外位置，再进门回到入口；特写返回恢复原漫游位置。
