## 改动

- `dev/minitool/make_leyuan.py`（新）：不改 `build.py`（别的会话在改它），先调 `build.py --ark` 打 ark 包，再在输出目录里给 `ark_cfg.js` 末尾加 `window.__RLP_233 = true;`（灯泡按钮才显示），在 `index.html` 的 `ark_cfg.js` 之后加 `<script async src="https://cdn.233xyx.com/h5ad/metah5ad_v1.min.js"></script>`（async：CDN 慢或不通时不挡启动），重新打 zip（根目录就是 `index.html`）。
- `dev/minitool/test_leyuan.py`（新）：包结构；手机横屏触摸点灯泡；本机模拟广告；页面里注入假的 `MetaH5Ad` 走真实 SDK 路径（回调 0→3→4 给提示、0→1 不给提示、`isAdSupport` 返回 0 只提示不放广告）；灯泡和齿轮的实际可点区域。12/12。
- 灯泡的触屏位置：原有 ark 验收发现，`ark.css` 用伪元素把 `.gear` 的可点区域撑到 44×44，灯泡放在齿轮左边会盖掉齿轮一截（可点区域 41→33，`test_ark.py` 失败）。改成触屏下灯泡放在画面右上角（`styles.css` 的 `#stage.touch .hint-btn { left: 65.9em }`），并把 `.hint-btn::before` 加进 `ark.css` 的 44px 伪元素规则；灯泡和齿轮的可点区域现在都是 44×44、互不重叠。
