# 模型现实尺寸表（人物 / 桌椅 / 道具）

所有章节的模型都按真实世界的大小建，**世界里 `scale` 一律为 1**；镜头、座位和摆放去适配模型，不要再用缩放凑画面。
这张表是可复用的：数字在 [`src/art/scale.js`](../src/art/scale.js)（`HUMAN`、`FURNITURE`、`ANIMALS`、`REAL.p4`），新章节直接 `import` 对照；量实际尺寸用 `python dev/plague4/measure_scale.py`（量的是第四灾，别的章节仿照它加 `REAL.pN`）。

## 四、允许的例外（都在 `REAL.p4` 里标了 `exempt` 并写明原因）

- **谜题沙盘上的小生物 / 贝壳 / 海胆**按格子放大（格 0.36 m），不按真实大小；`freeCrab`（被苍蝇人吃掉的那只）0.35 m，和 0.5 m 大的手相称。
- **可拾取的小物件**（兔心 / 鸟心 / 蟹肉、宝石）至少放大到 0.1 m，方便点击：心脏 0.12–0.14 m，宝石 0.26 m（镶在猫头鹰嘴里 / 石门上）。
- **公共模型**沿用第一灾比例：天堂门、木小屋门、猫头鹰图腾（2.4 m 高）、石门（盖住神殿塔的门洞）、圣水盆、吊架。
- 超自然生物（苍蝇人、蛹）按"能孵出一个成年人"定，和人物同大。

## 五、怎么复用

1. 建模：按真实尺寸直接建；要缩放就在工厂函数里 `bake(root, k)`（`src/art/props_flies_kit.js`）——外面包一层，内部缩放，世界里仍是 `scale = 1`，方法（`setOpen` / `setState` / `update` …）原样挂到外壳上。第四灾的蛹 1.35、兔 0.7、鸟 0.36、石板 0.55、心 0.45、窗 0.78、胡萝卜 0.6、地洞 0.8、兔洞 0.3 都是这么做的。
2. 摆放：`world.js` 里 `place(...)` 不再传 `scale`；人物按 `scale.js` 的 `HUMAN` 身高，坐着的用 `seatedTop` 校座位高度。
3. 验收：`python dev/plague4/measure_scale.py` 打印每个布景对象的 宽 × 高 × 深（只算可见网格）和现实参考，超出容差标 ✗（退出码 1）；人物表同时打印默认姿势的包围盒。新章节在 `scale.js` 里加 `REAL.pN`（键 = 该章 `world.js` 里 `W` 的名字），再仿照 `dev/plague4/measure_scale.py` 写一个量尺寸脚本。
4. 截图核对：`python dev/plague4/art_shots.py [名字片段…]`，输出在 `dev/plague4/media/art/`（本地，不入库）。
