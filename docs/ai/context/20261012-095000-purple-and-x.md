## 改动

1. **红色 → 紫色**：沿用上一版找出来的那批红色字面量（hex / `rgba()` / 裸 `'r,g,b'` / GLSL `vec3`），改用紫色映射（色相约 280°，饱和度略收，中调亮度 +0.08）。
   脚本留在会话草稿目录里（`recolor_purple.py`），做法是**先从改色之前的备份还原被改过的文件，再一次性应用**，所以不会和上一版的橘黄值叠在一起。
2. **手工调的**：湖面着色器 `lake.js` 的 `cRing1/cRing2/cShore/cDeep/cPool`（公式出来会被灰色湖面稀释，手调成更饱和的紫）；血触手 GLSL `vec3`；溪流 `RED` 数组；小船箱子（粉棕 → 米色）。
3. **上一版漏掉的两处**（红色判定的饱和度阈值 0.35 把它们筛掉了，这次放宽到 0.18 重扫截图才发现）：
   - **记忆场景棺材下面那摊“血泊”**（`buildings.js`，原来是灰紫偏红的 `#7e605c / #553e3d / #4a3433 / #8a6865`，图层名就叫 `memory_puddle_blood`），改成紫色；
   - **带刺水果**（`props_beach.js`）的纹路 `fruitRidge` 暗红棕和纹理里的橙棕斑点，改成深紫。
4. **文字里的“血” → x**（只改玩家看得到的字，物品 id / 变量名等内部名字不动）：
   - 章节名 `血灾 / Blood` → `x灾 / x`（`chapters/index.js`、`plague1/index.js`、`plague1/text.js` 的 `chapter`）；
   - 台词 `……锈湖才会停止流血。` → `……锈湖才会停止流x。`；
   - 物品 `装有血的壶 / Jug of blood` → `装有x的壶 / Jug of x`；
   - `暗红色的血灌满了木桶。` → `紫色的液体灌满了木桶。`；演示章节 `红宝石 / Red gem` → `紫宝石 / Purple gem`。
   - 打包后的 `game.js` 里已经没有“血”（包括 `血` 转义写法）。代码注释里还有“血”，不会进包。
5. **图标**：新增 `dev/minitool/make_icon.py`（以前图标是临时画的，没有脚本）。用当前游戏的记忆场景截图（UI 隐藏）+ 标题“锈湖：天堂岛”+ 副标题“第一灾 · x灾 · 3D”（紫色），输出 512×512 的 `icon.png`；
   旧图标另存为 `dev/minitool/_old/icon-before-x-purple.png`。
6. 界面里的红色（章节按钮高亮、危险按钮、启动报错字、容器报错横幅）一并改成紫色。

修复：它们 08:26 的发布包 `dev/minitool/dist-audio-release/style.css` 末尾保留了那份 `minitool.css`（经 `css_compat` 转写后的内容）。取出来后去掉 `build.py` 自己生成的 `html.no-flexgap … > * + *` 兜底那 7 行，
