## 背景

## 本地启动

- 服务：`http://127.0.0.1:8080/index.html?chapter=2`，`curl` 返回 200。
- 浏览器核对：`RLP.ready === true`，`RLP.bootError` 为空，开局视图 `overview`，物品栏为空。
- 非菜单切换的重载会走 `src/main.js:224` 的 `state.wipeAll()`，所以每次直接打开这个地址都是全新开局；从首页菜单选第二灾也可以。

## 攻略（按代码整理）

总目标：集齐 4 只青蛙 + 木头 + 蜡烛，煮出青蛙汤 → 喂给 Gerard 吐出钥匙 → 开厨房小木箱拿黑方块 → 放进神殿吊架通关。

### 操作

电脑端：WASD 走动，鼠标移向画面边缘转身，点击互动；物品栏用数字键（按一下选中，再点场景使用，再按同一个数字取消）；点画面下方 ▼ 或按 S 返回。进了人物或谜题特写后，要先返回才能继续走动。

### 路线

1. **神殿门外**：湖岸神殿门外左前方地上的木柴堆 → 木头。
2. **神殿里**：左边凳子上的腰带 → 腰带；右边深棕木柜 → 点柜门 → 转盘锁：中圈点 5 下，外圈点 4 下（顺序不限，点多了就继续转满一圈：中圈 8 步一圈，外圈 12 步一圈）。对齐后闪光、自动退回柜子 → 再点柜门 → 拿蛙笛。
3. **水泵空地（Ida）**：点 Ida（会说话）→ 选蛙笛点她，她开始吹 → 点她手里的笛子 5 次（等一个乐句吹完再点下一次，头顶青蛙依次变色）→ 第 5 次她睁眼停下 → 点头顶橙色青蛙 → 青蛙（橙）。第 5 次之前点青蛙只会叫一声。
4. **水泵空地（蛙卵盆）**：点 Ida 右边的浅木盆 → 俯视特写。先点一堆（它沉下去），再点它的配对（见示意图字母）；六对点完闪光，浮起一只青蛙，点它 → 青蛙，成就“第一只青蛙”。配错一对，所有蛙卵复位重来。拿走青蛙后连点空盆里的水 3 次 → 水中倒影（隐藏成就）。
5. **海滩右（睡莲）**：点浅水里的青蛙/棋盘 → 俯视特写。规则：只能横竖跳 1 或 2 格；落点必须是还没踩过的叶子（能跳到的叶子会变亮）；踩过的叶子沉没；叶子全踩完后最后跳终点。叶子没踩完就跳终点或无路可走 → 画面压暗，本关重来。共五关，第 5 关过关得青蛙。路线（列,行，从 1 起数，按示意图的编号）：
   - 第 1 关：(4,2) (5,2) (3,2) → 终点 (1,2)
   - 第 2 关：(3,2) (3,3) (5,3) (5,4) (5,2) (5,1) (4,1) (2,1) (2,3) (4,3) → 终点 (4,5)
   - 第 3 关：(3,5) (2,5) (2,3) (1,3) (1,4) (3,4) (3,2) → 终点 (3,1)
   - 第 4 关：(1,1) (1,3) (2,3) (3,3) (3,4) (2,4) (2,2) (4,2) (4,4) → 终点 (6,4)
   - 第 5 关：(4,4) (4,2) (2,2) (2,4) (3,4) (3,3) (2,3) (1,3) (1,1) → 终点 (3,1)（圆木桩）
   - 代码接受所有合法路线，上面只是其中一条。
6. **海滩左（David）**：点 David 进特写 → 选腰带点他 → 他系上腰带，镜头转到石头特写 → 点脚边的青蛙 → 青蛙。
7. **厨房（石屋）**：进石屋，桌上的碗和蜡烛各拿一个；点大锅进特写；4 只青蛙逐只选中点锅（一只一只跳进去）；选木头点锅（或锅下的火圈）；选蜡烛点火圈点燃（蜡烛不消耗，没放木头时无效）；选碗点锅 → 碗变青蛙汤。点 Margaret 会冒出“4 × 青蛙”的提示。
8. **森林白树空地（Gerard）**：点 Gerard 进特写 → 再点他，他举起金钥匙吞下 → 选青蛙汤点他，他喝汤，碗回到物品栏 → 选碗点他，他吐出绿液 → 点他手里的碗进俯视特写 → 点浮起的小金钥匙 → 钥匙，成就“一把生锈的钥匙”。
9. **回厨房**：选钥匙点左边小木箱 → 黑方块飘起；点方块看回忆（Caroline 抱着婴儿），再点一次方块 → 黑方块。
10. **神殿**：选黑方块点吊架 → 自动完成：方块入窗，吊架降进圣水盆，镜头拉近到画，青蛙被抹掉，红斗篷女人被框住 → “第二灾 · 完”。

### 容易卡的地方

- 汤必须先给 Gerard 喝，之后才能把碗给他；空碗对他无效。
- 木头要先放在锅下，蜡烛才点得着。
- 4 只青蛙：蛙卵盆、睡莲、David、Ida（橙），Ida 那只要等第 5 次变色。
- 转盘锁点多了不会失败，继续转到整圈即可。
- 不确定下一步时，点 Ida / Gerard / Margaret 会冒出思考泡提示需要什么。
