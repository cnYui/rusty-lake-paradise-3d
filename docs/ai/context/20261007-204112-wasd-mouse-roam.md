# WASD 与鼠标漫游改造

## 背景

海滩 `beach_mid` 是固定镜头，船位于画面右侧之外，原有船热点只绑定 `beach_right`。玩家必须先发现边缘方向箭头，导致“船不在视野内、无法进入船”的反馈。

## 决策

- 保留固定镜头、方向箭头和所有谜题特写，避免破坏原版屏幕节点式解谜流程。
- 在室外普通视图按住 `W/A/S/D` 时进入临时自由漫游；`W/S` 按当前水平朝向前后移动，`A/D` 横向移动。
- 鼠标相对进入漫游时的位置控制 yaw/pitch；`Esc` 恢复当前固定镜头。
- 漫游相机位置不写入存档，进入近景或切换 zone 时由 `views.go()` 收回相机控制。
- 移动边界使用 `layout.js` 的岛屿轮廓，并在天堂门解锁前阻止穿过栅栏进入森林，防止绕过章节谜题。
- 漫游状态下热点按室外 zone 放宽当前 view 过滤，但仍经过对象可见性、射线命中和 `when` 条件；室内热点不会被放开。
- `beach_mid` 增加隐藏入口代理 `boat_entry`，使船在中景也有可达入口；船原本的 `beach_right` 热点继续保留。

## 同步修复

- 湖区棺材升起后，血池再次点击会进入 `coffin` 近景，六枚钉子在近景逐个可由真实射线命中，自动流程更新为 77 步。
- 总览入口代理、森林数组坐标恢复和湖区画作坐标问题沿用本轮已有上下文记录。

## 验证

- `node --check`：`views.js`、`hotspots.js`、`ui.js`、`debug.js`、`beach.js`、`forest.js`、`lake.js`、`main.js` 全部通过。
- 浏览器实测：`beach_mid` 按住 `D` 后 `freeMode: true`，移动鼠标改变镜头，`boat_entry.onScreen: true`；点击代理后进入 `boat_close`，无运行时错误。
- 完整 `RLP.autoplay({ stepDelay: 5, fast: true })`：`ok: true`、`steps: 77`、`total: 77`、`failedStep: null`、`plague1_complete: true`、`errors: []`。

## 已知边界

漫游采用岛屿轮廓和栅栏门禁作为基础碰撞，树木、建筑外墙等装饰物没有统一碰撞体；它们仍通过热点和固定镜头承担交互。室内和特写场景继续使用固定相机。
