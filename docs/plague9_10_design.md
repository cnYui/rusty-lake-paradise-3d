### 谜题规则（`src/chapters/plague9/rules.js`，不 import three）

1. **啄木鸟**：树干上 5 个疤（从下往上 0–4），第 `BARK_SPOT = 3` 个是发白翘起的松树皮。点哪个疤啄木鸟就飞过去啄三下；啄的是松树皮那块就掉下来。
2. **研磨机**：`GRIND = { bark: powder_brown, shell: powder_white, blue_stone: powder_blue, moon_stone: powder_red, bones: powder_bone }`。一次放一样，摇柄磨好后从出料口拿走粉末才能放下一样。
3. **篝火**：`SHADOWS = { powder_brown: aries(0), powder_white: libra(6), powder_blue: gemini(2), powder_red: scorpio(7), powder_bone: mother }`。星座编号 0–11 从白羊到双鱼。撒过的粉末记在 `shadow_<星座>` 旗标里，塔门拱上对应的符号一直亮着那种颜色（玩家不用记）。
4. **星座盘**：12 格，三根针（针尖棕 / 白 / 蓝，`HANDS`）。点一根针，它顺时针走一格。三根针分别停在 `DIAL_ANSWER = [0, 6, 2]` 就开抽屉。开局 `[9, 3, 11]`。
5. **月相仪**：太阳灯在中间，地球臂 8 个位置（`earth`），月亮绕地球 8 个方向（`moon`，绝对方向）。点地球 / 月亮各走一格。月亮正好在地球背着太阳的那一侧（`moon === earth`）就是月食，任何一个地球位置都算。开局 `earth = 2, moon = 6`（月亮在太阳和地球中间）。
6. **影子**：蜡烛在地上 12 个符号（同星座编号）之间挪，五个挂件的影子按“点光源 → 挂件 → 墙面”的投影落在墙上；粉笔轮廓画在蜡烛放在天蝎（`CANDLE_ANSWER = 7`）时的影子位置上，所以只有这一个位置五个都对上。影子是按投影算的平面剪影（不用实时阴影），挪蜡烛时连续移动。
7. **母亲**：骨粉撒进篝火 → 火里浮出母亲的影子 → 火烧尽，黑方块留在灰里。

### 与原作的差异

- 原作星座盘、望远镜、月相面板、挂件影子要来回解好几轮；重制版每样只解一次，线索都来自篝火里的星座黑影（针尖颜色 = 粉末颜色）。
- 原作的月相面板是三根杆拼月相，重制版改成真 3D 的月相仪（太阳灯、地球、月亮），规则是“地球挡在太阳和月亮中间”。
- 原作用镐敲天上的血月，重制版是月食后一道红光落进塔外的雪地，冻在冰里，用镐凿出来。
- 望远镜只是布景；塔顶三个火盆和湖上的黑鸟改成一个烽火：点亮以后怕光的猫头鹰飞走，木箱打开。
- 原作火上绑着的女人改成火光里浮出的影子；挂件改成五个家人面具的动物（兔、雉、鹿、鸽、野猪），和第十灾呼应。
- 原作第九灾结尾湖边立起的黑色木头猫头鹰放到第十灾。

### 谜题规则（`src/chapters/plague10/rules.js`，不 import three）

1. **鼓**：`RHYTHM = ['L', 'R', 'R', 'L', 'R']`。点 Nicholas 他敲一遍（左手低音、右手高音）；玩家点鼓面左半 / 右半照着敲，敲错从头来（敲错的那下正好是第一拍就算开了头），进度存 `drum_step`。
2. **骨箭**：箭杆 + 羽毛 → 带羽毛的箭杆；箭杆 + 尖骨头 → 装了骨头的箭杆；两样再加上缺的那样 → 骨箭（任意顺序）。
3. **射苹果**：苹果没顶在 David 头上时 Gerard 不射。
4. **脸**：五道竖条，每点一下按 白 → 绿 → 红 → 白 轮换；`FACE = ['green', 'white', 'red', 'white', 'green']`（墙上的面具画）。存 `face`。
5. **孵小鸡**：`egg_in_pan` 和 `stove_lit` 都有了就孵出来（顺序随意）。
6. **骨头字母**：四组骨头各转 0–3 个 90°。合格的转角：O 任意、W 只有 0（转 180° 是 M）、L 只有 0、S 是 0 或 2（S 转 180° 还是 S）。开局 `[1, 2, 3, 1]`。
7. **字母门**：四列 `LETTERS`，每列 6 个字母循环，读成 `OWLS` 就开。开局全是第 1 个字母。
8. **六边形**：中间一块 + 周围六块，每块点一下转 60°，七块都回到 0 才拼成猫头鹰。开局 `[2, 4, 1, 3, 5, 2, 4]`（中间那块不在 0，不会开局就有一块对上以外的巧合）。
9. **面具**：`MASK_OF = { gerard: mask_boar, david: mask_rabbit, ida: mask_pheasant, margaret: mask_pigeon, nicholas: mask_deer }`；给错不接（不消耗）。五个都戴上，`all_masked`。

### 与原作的差异

- 原作的地图、刻度尺、O / W / L 石环（找井、开井盖）这一段删掉：井一开始就能下去，字母门挡着。
- 原作猎人第一次射偏；重制版没顶苹果他不射，顶了一次就中。
- 原作五个雕像各有一个小机关；重制版五个面具直接放在拱龛里（井下的谜题是字母门和六边形）。
- 原作给 Ida 画脸要先在她掌心蘸颜料；重制版点竖条轮换颜色。
- 火炬柱：原作十根火炬柱分散在岛上，重制版是五个家人各自身边一根（戴上面具就点着）加猫头鹰门前两根。
- 结尾的大火和回忆剪影做成一段红色幻象（平面剪影卡片），不做燃烧的人。
- 井下做成三间石室：前室（梯子、字母门）→ 拱龛室（五个面具）→ 右手边的鹰室（石鹰、六边形、黑影、Elizabeth）。
- 鼓的左右按玩家看过去的左右算（鼓面左半边 = Nicholas 的右手），提示和测试都按这个说。
- 苹果顶在 David 的帽子顶上（按网格头部包围盒的最高点放，挂在头骨骼上跟着动）。
- 画好脸以后 Ida 直接把蜡烛递给玩家（她的手掌在脸部特写画面外）；万一物品栏没收到，空地上还能从她掌心里拿。
- 戴上面具：五个人都换成自带动物头的网格模型（站在同一个位置）；Ida 戴上后是 `ida_pheasant`（野鸡面具、棕色泡泡袖裙，2026-11-03 起）。
- 湖边那块大石头紧贴着猫头鹰门的右边（栅栏右半边埋在石头里），所以门前两根火炬柱放在栅门外两边（右边那根贴着石头脚），戴面具的五个人都站在栅栏里门的左边；`p10_temple` 机位从正面稍偏左看过去，石头只占画面右边。
- 塔门前的大石头和第九灾一样压进地里（挡门、挡鼓的镜头）。
