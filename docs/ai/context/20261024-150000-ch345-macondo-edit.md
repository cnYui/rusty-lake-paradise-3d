# 2026-10-24 第三、四、五灾通关录像按《马孔多在下雨》剪成 35 秒混剪

## 需求

用户要把之前录制的第三、四、五灾通关录像，用 B 站 BV1yr421M7Ai 的 BGM《马孔多在下雨》（UP 主“睡到三百年后”，只有 36 秒），按下面这些手法剪：动作顺接、匹配剪切、跳切、插入镜头、隐形转场、J-cut / L-cut、交叉剪辑、蒙太奇。

## 过程

- **取 BGM**：`yt-dlp` 对这个视频报 `Unable to extract initial state`，B 站接口对命令行请求回 412；改用浏览器打开视频页，读 `window.__playinfo__` 里的 DASH 音频地址（30232，AAC 约 102 kbps），带 `Referer` 用 `curl` 下载，447 KB，时长 35.04 秒，转成 `dev/common/media/edit_ch345/bgm.wav`。只作本地使用（`dev/common/media/` 被 `.gitignore` 忽略），版权归原作者，不入库、不随游戏部署。
- **节拍**：`librosa` 在这台机器上 import 失败（numba 要 NumPy ≤ 2.3，现在是 2.5），改用 `scipy` 自己算频谱通量 + 自相关：约 72.8 BPM，一拍 0.824 s，第一拍在 0.46 s（八分音符 0.412 s）；1–32 秒能量平稳，最后 3 秒淡出。
- **选镜头**：三段录像各抽了带时间标记的帧图（`mksheet` 思路：每格左上角标秒数）逐段看。注意第四灾录像是修复“苍蝇挡镜头”之前录的，蟹盘里 140–190 秒有苍蝇的黑影，混剪里没有用那段；第三灾 0–8 秒、第四灾 0–5 秒、第五灾 0–4 秒是黑屏载入页，标题菜单要从第五灾 5 秒以后取（那时菜单上已亮起五章）。
- **脚本**：`dev/common/make_ch345_edit.py`（`storyboard` 出分镜图、`render` 渲染）。44 个镜头的起点都踩在拍点上，边界按 30 fps 四舍五入到帧，累计不漂移（1051 帧 = 35.04 秒）。画面轻微调色（对比度 1.05、饱和度 0.92）。游戏原声压到 0.35 垫在 BGM 下面，整体响度 −19.6 dB（BGM 原本 −20.0 dB）。

## 结构和手法

| 时间 | 段落 | 手法 |
| --- | --- | --- |
| 0–1.3 s | 开场：标题画面从黑里淡入 | 淡入 |

| 7.9–19.4 s | B 段：一拍一个镜头，三章交叉 | 匹配剪切（方格谜题 → 蟹盘 → 菜地；星图 → 陶轮圆盘 → 餐盘）、跳切（星图连线同一个镜头隔几秒再切，连续四次）、插入镜头（红心、捕蝇草、金书、花）、动作顺接（剁菜的刀落下时切走）、L-cut（星图的声音拖进陶轮镜头） |
| 19.4–24.4 s | C 段：蒙太奇，半拍一个镜头 | 12 个镜头在三章之间来回切 |

| 27.7–31.0 s | “圣水盆”交叉剪辑，汇到闪白 | 第四灾 → 第五灾 → 第三灾金色吊架，在闪白那一帧切（隐形转场）、白里出水柱（J-cut：水声提前 0.35 s） |
| 31.0–33.4 s | 画框 | 匹配剪切（第三灾画框 → 第五灾画框）、L-cut |
| 33.4–35.0 s | 三章结尾卡连切，BGM 淡出 | — |

## 限制

- BGM 只有 35 秒，所以成片也是 35 秒；要更长的版本得换更长的曲子或把素材再抽几段。
- J-cut / L-cut 靠游戏原声（点击、剁菜、水声）做，原声本身很轻，效果是细微的；要更明显得单独加音效。
- 第三灾录像还是旧的程序化人物（录于 2026-10-20），第四灾录像里的蟹盘镜头是修复前的。
- 成片 `dev/common/media/edit_ch345/ch345_macondo.mp4`（9 MB，1280×720，h264 + aac）在本地，不入库。
