## 看完整个拼图后整理的第二灾流程（待逐帧核对）

- 开场：总览，标题“第二灾 / 蛙灾”，湖水是灰色的（没有血）。天堂门开着，小屋门也开着。
- 海滩：David 站在石头上不停从裤兜里掏青蛙吃。给他腰带后他不再吃，石头上留下一只青蛙。
- 海滩右侧湖面：睡莲叶谜题（俯视）。青蛙每片叶子只能踩一次，离开后叶子沉下去；要走完所有叶子停在石头上，
  一共有好几关，最后一关的终点是木桩 → 青蛙。
- 白树空地（第一灾 Margaret 和山羊的位置）：Gerard（大胡子、帽子、马甲）把钥匙吞进嘴里，脑袋上的思考泡是一碗汤。
  给他青蛙汤，他喝完吐进碗里 → 检视碗 → 钥匙。
- 水泵空地（大树、黑色荆棘，第一灾的位置）：Ida（红色长发、白眼睛、棕色裙子，头顶青蛙）说“哥哥 很高兴能再一次见到你.”，
  思考泡是笛子。旁边的浅盆是蛙卵谜题（点蛙卵团）。解开后得到青蛙 + 一段幻象（男孩和鹿头人）+ 成就。
  给她蛙笛，她吹奏时头顶青蛙会变色，点青蛙得到（橙色）青蛙。
- 石屋（第一灾的餐厅换成了厨房，灰泥墙）：Margaret 站着搅大锅，要 4 只青蛙。小桌上有蜡烛和碗，左边有个锁着的箱子。
  锅下放木头、用蜡烛点火，放 4 只青蛙 → 用碗盛出青蛙汤。
- 神殿：门外能捡到木头；殿内有凳子（腰带）、带同心圆转盘锁的柜子（转好后得到蛙笛）、带翅膀的吊架、圣水盆、画。
- 用钥匙开箱子 → Caroline 抱着婴儿的回忆（“Jakob Jakob 我的第一个孩子...”）→ 墙上出现黑方块。
- 黑方块放进神殿的翅膀吊架 → 降进圣水盆 → 光 → 画里方块发光，把穿红斗篷的女人框起来（结尾）。
- 物品：青蛙、蜡烛、碗、木头、腰带、蛙笛、青蛙汤、钥匙、黑方块。
