# 第六至第十灾视频对照建模计划

## 目标

从本地天堂岛原作视频第六至第十集提取关键近景帧，与当前 3D 道具工厂逐项核对，补足轮廓、分件、材质和高曝光细节。保持章节逻辑和交互接口不变，修改后完成语法、章节规则和模型构造回归。

## 参考素材

- 视频目录：`/home/rpartx3080/CodeSpace/games/.scratch/paradise-original-video-BV1bo4y1y7fm/`
- 章节视频：`p06-paradise-06.mp4` 至 `p10-paradise-10.mp4`
- 本轮近景帧：同目录下新增 `focus/`，文件名包含章节和时间码。
- 已有联系图：同目录下 `reference-sheets/`，用于快速定位镜头，不作为唯一建模依据。

## 核对优先级

1. 第六灾：牛头骨、空瓶/量瓶、瘟疫法杖、落地钟、牙齿、CURE 书。
2. 第七灾：冰淇淋、雪景球机器、雪人、松鼠冰锥树、冰中青年冰块。
3. 第八灾：曼陀林、蝗虫/蚱蜢、卵鞘、猫头鹰树、船、蛾群。
4. 第九灾：啄木鸟树干、研磨机、篝火、月相装置、阁楼挂件和影子。
5. 第十灾：在已有苹果、虫、刷子、蛋、小鸡细节基础上，用近景帧确认比例和层次，必要时做局部修正。

## 实现边界

- 保持 `FACTORIES` 工厂键、返回对象、`setState` / 动画方法、`userData` 点击盒名称和章节物品 ID 不变。
- 只增加或调整局部几何、贴图和材质层次；不改变章节状态真值、热点条件、相机契约和存档字段。
- 新增几何必须使用现有 `props_*` 工具函数和材质风格，避免引入新的运行时依赖。
- 参考帧和测试日志保存在 `.scratch` / `.logs`，不提交视频或抽帧大文件。

## 验收

- `node --check` 覆盖所有修改的模型文件。
- `node --test dev/plague6/test_plague6.mjs` 至 `dev/plague10/test_plague10.mjs`。
- 逐个构造高曝光工厂并检查关键子物体、点击盒和 `setState` 可用。
- `git diff --check`。
- 浏览器 Playwright 依赖若仍不可用，记录替代验收及未完成项，不把构造探针冒充完整浏览器验收。
