- 参考画面确认的地点顺序：天堂门与病牛、牛皮疫病图案、森林木桶、6×5 菜地、白底连点星图、厨房、汉堡菜单、饭桌、神殿画作。

## 章节流程

1. 开场总览进入海滩；天堂门旁可取得植物盆和刀。
2. 在病牛特写中用刀取下生肉；牛皮上的五段疫病图案是本章主题提示。
3. 进入 6×5 菜地，按左侧红色计数完成每行蔬菜布局，得到生菜、番茄、黄瓜。
4. 森林木桶取得奶酪；白底星图按五组连点完成，得到黑方块。
5. 厨房把生肉切成肉馅，在锅里加入肉馅和蔬菜，点火煮成汉堡肉；拿盘子盛出。
6. 饭桌按 Rusty Lake Burger 菜单顺序叠放面包、生菜、番茄、黄瓜、肉馅、奶酪，得到完成的汉堡。
7. 把汉堡交给 Gerard，打开神殿吊架并放入黑方块；画作发光后框住红衣女人，设置 plague5_complete。
