## 1. 总体

- 地图沿用第一灾的天堂岛（`src/art/layout.js` 的坐标、地形、森林、石屋、小屋墙、神殿、塔），第二灾只换“布景”：
  - 湖水干净：`world.lake.setBlood(0)`、`setPool(false)`。
  - 森林里多了横向白雾带（`src/art/mist_p2.js` 的 `buildForestMist()`，章节 setup 时加进 exterior）。
  - 天堂门没有门板（`paradise_gate` 摆上后把 `gate_doors`、两个小窗、Gerard 的眼和手全部隐藏），不注册门禁。
  - 小屋门板不见了，只剩门框（`shed_door` 摆上后隐藏 `shed_doors`、`padlock`、`shed_bolt`），不注册门禁。
  - 第一灾的竹子、果子、小船、水泵、木桶、猫头鹰、山羊、坐着的 Margaret、灵魂、棺材、血池都不出现；
    `world.colliders` 里它们的碰撞要在 setup 里删掉（水泵、猫头鹰、Margaret、木桶、山羊、小船）。
- 开局即可自由走遍全岛（门都开着）。室外开放视图自由漫游；人物和谜题是特写（closeup 固定镜头）。
- 石屋室内复用 `house_int` 区域，第二灾里是 **Margaret 的厨房**（灰泥墙，没有画）；神殿复用 `temple_int`，多了左边的凳子和右边的转盘锁柜子。
- 物品栏 12 格（第二列在超过 6 件时展开），原作同样会同时持有 7 件。

## 3. 谜题与流程（全部按视频）

### 3.1 David（第 4 只青蛙）
1. 点 David → 进入特写 `david`。在特写里点他 → 播放一次“吃青蛙”（嘴里鼓出绿色 → 青蛙头朝下滑出挂在胸前 → 他拉开裤腰把青蛙塞进去，约 2.4 秒），可无限重复。
2. 选中 **腰带** 点他（特写里或漫游时都行）→ 腰带用掉，他系上腰带，表情变愁苦，不再吃青蛙；他脚边石头上留下一只绿青蛙。
3. 点石头上的青蛙 → 得到 **青蛙**。
- 旗标：`david_belt`、`david_frog_taken`。

### 3.2 睡莲叶跳青蛙（第 3 只青蛙）
- 从海滩右点浅水里蹲在叶子上的青蛙 → 俯视特写 `lily_pads`（相机正上方，略带一点偏移，`look: 0`）。
- 网格：6 列 × 5 行，格距 0.55 m，(列, 行)；第 0 行在北（靠岸，画面上方）。
- 规则：青蛙只能上下左右跳 **1 格或 2 格**（2 格可以越过空水面、已沉的叶子，也可以越过还没沉的叶子）；
  每片叶子只能踩一次，青蛙离开的叶子（含起点石）变暗下沉消失；**能跳到的叶子会变亮**；
  所有叶子都踩过后跳上终点 → 过关，终点原地变成下一关起点，新叶子从小点长出来；
  叶子没踩完就跳上终点，或者无路可走 → 画面压暗约 0.5 秒，**只重置当前这一关**。
- 关卡（S = 起点，T = 终点，其余是叶子）：

| 关 | 起点 | 终点 | 叶子 |
|---|---|---|---|
| 1 | (3,3) | 石 (0,1) | (2,1) (3,1) (4,1) |
| 2 | (0,1) | 石 (3,4) | (1,0) (3,0) (4,0) (2,1) (4,1) (1,2) (2,2) (3,2) (4,2) (4,3) |
| 3 | (3,4) | 石 (2,0) | (2,1) (0,2) (1,2) (0,3) (2,3) (1,4) (2,4) |
| 4 | (2,0) | 石 (5,3) | (0,0) (1,1) (3,1) (0,2) (1,2) (2,2) (1,3) (2,3) (3,3) |
| 5 | (5,3) | 圆木桩 (2,0) | 同第 4 关 |

- 参考解：1：(3,1)(4,1)(2,1)→T；2：(2,1)(2,2)(4,2)(4,3)(4,1)(4,0)(3,0)(1,0)(1,2)(3,2)→T；
  3：(2,4)(1,4)(1,2)(0,2)(0,3)(2,3)(2,1)→T；4：(0,0)(0,2)(1,2)(2,2)(2,3)(1,3)(1,1)(3,1)(3,3)→T；
  5：(3,3)(3,1)(1,1)(1,3)(2,3)(2,2)(1,2)(0,2)(0,0)→T。
- 第 5 关过关：青蛙从木桩上消失 → 得到 **青蛙**。之后棋盘只剩木桩。
- 旗标：`lily_level`（1..5，当前关）、`lily_done`。关内的进度不存档（重进特写从本关起点重来）。
- 每个格子一个热点 `lily_<列>_<行>`，`when` 只在该格当前有可跳目标时为真（便于测试和真实点击）。

### 3.3 蛙卵盆（第 1 只青蛙 + 隐藏成就）
- 点 Ida 右边的浅木盆 → 俯视特写 `spawn_basin`。盆里 12 堆白色蛙卵（其中 6 堆旁有芦苇）。
- 规则见 §3.3.1（由逐帧分析确定）。清空所有蛙卵 → 成功闪光，一只青蛙从水下浮起；点它 → 得到 **青蛙**，成就 `the_first_frog`（粉笔青蛙图标）。
- 之后点空盆的水 → 旧胶片纹理转场，水面浮现半透明的年轻男子（Jakob）和他右后方的鹿头人，成就 `reflection_in_the_water`（粉笔鹿头）。幻象一直留着。
- 旗标：`spawn_cleared`、`spawn_frog_taken`、`reflection_seen`。

### 3.4 Ida 与蛙笛（第 2 只青蛙，橙色）
1. 点 Ida → 特写 `ida`。第一次点她：顶部字幕“哥哥 很高兴能再一次见到你.”；之后点她：思考泡（竖笛）。
2. 选中 **蛙笛** 点她 → 笛子用掉，她闭眼竖握蛙笛吹奏，黑色音符 ♪♫ 从头两侧飘起。
3. 青蛙按固定顺序变色：荧光黄绿 → 橙 → 绿 → 青绿 → 荧光黄绿 → 橙；每次变色瞬间全屏暖金色闪光（`ui.flash('#e8c27a')` 一类）。
   - 本复刻的触发：吹奏时**点她手里的笛子**（热点 `ida_flute`）= 她吹完一个乐句，青蛙换到下一个颜色（乐句之间有约 1.2 秒冷却）。点青蛙只会鼓起喉囊叫一声。
   - 第 5 次变色（第二次变成橙色）时她睁眼、停止吹奏；这时点青蛙（`ida_frog`）→ 得到 **青蛙**（橙色，物品 id `frog_orange`）。
   - 远景里她之后双手下垂，不再拿笛子，头上没有青蛙。
- 旗标：`ida_talked`（0/1/2）、`ida_playing`、`ida_phrase`（0..5）、`ida_frog_taken`。

### 3.5 厨房：青蛙汤
- 小桌上：**碗**、**蜡烛**（点着），点了直接拿。小木箱：点它 → “锁上了”。
- 点 Margaret → 思考泡“4× 青蛙”（自绘）。点锅 → 特写 `cauldron`。
- 锅接受：青蛙（`frog` / `frog_orange`，每只单独用，用掉）——青蛙跳到搅棍顶端、掉进锅里，锅口放出白色放射光；
  **木头**（用在锅下 / 火圈）→ 锅架下出现交叉木柴；**蜡烛**用在木柴上 → 点火（蜡烛不消耗，没木头时无效）。
- 4 只青蛙 + 火都齐了以后，选中 **碗** 点锅 → 碗换成 **青蛙汤**（同一格）。不满足时用碗没有反应（摇一下）。
- 旗标：`kitchen_bowl_taken`、`kitchen_candle_taken`、`margaret_asked`、`pot_frogs`（0..4）、`pot_wood`、`pot_lit`、`soup_taken`。

### 3.6 Gerard：钥匙
1. 点 Gerard → 特写 `gerard`。第一次在特写里点他：他从头顶举起一把金钥匙晃一晃，仰头张嘴把钥匙吞下（约 6 秒）。之后点他：思考泡“冒尖的一碗汤”。空碗对他无效。
2. 选中 **青蛙汤** 点他 → 碗悬在他头顶倾斜，绿汤倒进他张开的嘴里；碗空了回到物品栏（青蛙汤 → 碗）；他瞪圆眼睛呆住，然后冒出思考泡（空碗）。
3. 选中 **碗** 点他 → 碗交给他，他弯腰双手捧碗，约 4 秒后紧闭双眼吐出一道亮绿液体进碗里，然后直起身、眼皮半垂、一手托碗。碗从此留在他手里。
4. 点他手里的碗 → 俯视特写 `gerard_bowl`（灰绿背景，他的手托着碗，绿色呕吐物里一把小金钥匙，钥匙浮上液面）；点钥匙 → 得到 **钥匙**，成就 `a_rusty_key`（粉笔钥匙图标）。
- 旗标：`gerard_swallowed`、`gerard_drank`、`gerard_bowl`、`key_taken`。

### 3.7 箱子与回忆：黑方块
1. 选中 **钥匙** 点厨房的小木箱 → 箱盖向后掀起，钥匙用掉；一个黑色小方块翻转着从箱子里飘起，悬在箱子上方。
2. 点方块 → 回忆：方块摊开成一条黑线，描出墙上的矩形黑框；墙面叠上灰白雾树纹理、画面去饱和；Caroline 抱着婴儿在框前淡入并轻轻摇晃；字幕“Jakob Jakob 我的第一个孩子...”；然后倒放结束，方块重新悬浮。
3. 再点方块 → 得到 **黑方块**。
- 旗标：`chest_open`、`memory_seen`、`cube_taken`。

### 3.8 神殿
- 门外木柴堆 → **木头**（`wood_taken`）。
- 凳子上的 **腰带**（`belt_taken`）。
- 吊架：点 → 特写 `holder`；在特写里点 → 上下拉开露出方窗（`holder_open`）。
- 柜子：点 → 特写 `cabinet` → 点门上的转盘锁 → 特写 `dial`。
  - 三圈：内圈固定；**中圈**每点一次顺时针转 45°（初始比解开位置顺时针多 135°，即再点 5 次）；
    **外圈**每点一次顺时针转 30°（初始比解开位置逆时针 120°，即点 4 次）。
  - 解开时：9 点外框“=”对外圈“//”、中圈外尖三角和内圈内尖三角拼成菱形；3 点外框“—”、外圈单线、中圈销子连成横线；12、6 点中圈销子接内圈刻线。
  - 全部对齐 → 成功闪光，锁中心变成实心灰圆 → 自动退回柜子特写 → 点柜门 → 门消失 → 得到 **蛙笛**。
  - 旗标：`dial_mid`（0..7 当前步）、`dial_out`（0..11）、`dial_solved`、`cabinet_open`、`flute_taken`。
- 结尾：选中 **黑方块** 点吊架（已拉开，没拉开时先拉开）→ 方块放进方窗，上下合拢成金盒 → 自动回到神殿全景，金盒沿绳降进圣水盆，盆口射出光束 → 自动拉近到盆正面的画：画里方块变成发光白方块 → 射出光线抹掉右下角两只青蛙 → 白框框住红斗篷女人 → 结尾卡“第二灾 · 完”。
  - 旗标：`cube_inserted`、`holder_closed`、`holder_lowered`、`frogs_banished`、`woman_framed`、`plague2_complete`。
