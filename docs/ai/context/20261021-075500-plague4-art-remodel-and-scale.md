## 做了什么

**美术（`src/art/`）**

- 拆成四个文件：`props_flies_kit.js`（工具：渐细管、合并几何、`bake` 烘焙缩放）、`props_flies_creatures.js`（苍蝇人、蛹、寄居蟹、海胆、沙钱终点、螺壳、兔、鸟）、`props_flies_book.js`（书、窗）、`props_flies.js`（心 / 宝石 / 蜡烛 / 胡萝卜 / 地洞 / 木板 / 捕鸟石板 / 木箱 / 铁锅 / 石门，并统一导出）。`world.js` 仍只 `import * as art from props_flies.js`。
- 苍蝇人：防毒面具头 + 两只透镜 + 长喙 + 触角，黑羽毛外套（合并成一个网格），苍白瘦手臂，靴子，浅黄绿翅脉；`setKneel(k)` 在悬停和跪地进食之间连续过渡。
- 蛹：车削出的连续身体，十一道环节，背上两片深色背甲，`setOpen` 裂开。
- 寄居蟹 / 贝壳：螺旋纹车削螺壳，贝壳尖端指向引导方向，脚下一枚淡箭头；海胆 38 根刺合并成一个网格；终点是带 X 的沙钱。
- 兔 / 鸟：`setDead(bool)`，死后兔侧躺、鸟翻倒、眼睛是叉；吃完后尸体留在原地，蟹留下空螺壳。
- 书：摊开的跨页由画布画出（猫头鹰图腾 + `S:Ⅰ`、轮盘与长生不老药配方图 + `↑:3`、取出记忆 + `8 ⬡ ⊖`、水盆 + `△=Ⅹ` + 猫头鹰脸），封面是金框棕皮；`setOpen` / `setSpread` / `flipTo`（带翻页动画）。
- 窗：拱形双扇百叶 + Ⅰ–Ⅻ 罗马数字滑轨 + 四枚纹章滑片（`tabs`、`slotCenter`、`setState(numbers, open, selected)`），打开后露出赭黄色天空和灰山；一个坑：材质同时给底色和贴图会让颜色相乘变暗，统一改成 `#ffffff` + 贴图。
- 物品栏图标（蜡烛、胡萝卜、蟹肉、心、宝石）随新模型自动更新，截图确认。

**现实尺寸（`src/art/scale.js`、`docs/art_scale.md`）**

- 新增 `scale.js`：`HUMAN`（各人物身高）、`SEATED_RATIO` / `seatedTop`、`FURNITURE`、`ANIMALS`、`checkSize`、`REAL.p4`（第四灾每个布景对象的期望尺寸，例外写明原因）。
- 新增 `dev/plague4/measure_scale.py`：量每个布景对象（只算可见网格）和所有人物默认姿势的包围盒，对照表，超出容差标 ✗ 并以退出码 1 结束。最终 **布景模型超出容差 0 个**。
- 世界里不再用 `scale` 凑镜头：蛹 1.35、兔 0.7、鸟 0.36、石板 0.55、心 0.45、窗 0.78、胡萝卜 0.6、地洞 0.8、兔洞 0.3 全部用 `bake` 烘进模型，`place(...)` 不再传 `scale`；苍蝇人 1.25 → 1。相机按新尺寸拉近（`bird_clearing` / `trap` / `rabbit` / `pump_clearing` / `pit` / `window` / `book` / `crab_feast`），新增视图 `book`。
- 桌椅人物的相对关系实测：圆桌高 0.76，高背椅椅面 0.49、高 1.23，尼古拉斯坐着头顶 1.64（含举起的方块，坐高推算 1.47），回忆里的父亲 1.64、少年 Jakob 1.32、木凳 0.50，木箱 0.79 × 0.60 × 0.59，铁锅口径 1.04。站姿身高都在表值 +0.05 以内；`soul`（2.83）、`ida` 默认姿势（1.77）偏高，是姿势 / 道具撑出来的，留作后续核对。

**场景同步（`world.js`，美术负责）**：地洞里的 Gerard 一直可见；盖坑的三块宽木板（原来是三根树枝）；兔 / 鸟吃完后留下尸体；蟹被吃后留下空螺壳；寄居蟹出发前朝右；窗滑片选中态从 `p4_window_selected` 读取。
