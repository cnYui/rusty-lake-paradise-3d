# 天堂岛道具建模重做计划

## 目标

在不改变章节状态、热点和现有模型工厂接口的前提下，补强第十灾高曝光小道具的可识别细节。当前工作区没有天堂岛原始视频或抽帧目录，只有章节设计记录、程序化模型和验收素材，因此本轮结果只能做代码级与验收画面对照，不能声称完成逐帧复刻。

## 本轮范围

- `src/art/props_p10.js` 的苹果、虫、刷子、蛋、小鸡。
- 细节方向依据第十灾设计记录和现有场景语义：苹果的凹陷/叶柄、虫的分节与头部、刷子的木柄/箍/刷毛、蛋的尖圆比例、雏鸡的翅膀/脚/眼喙。

## 实现约束

- 保留 `FACTORIES` 中的工厂名、返回对象结构、现有 `setState` 与点击盒命名。
- 仅增加局部几何和材质层次，避免改变物体尺寸导致热点或构图漂移。
- 完成后至少运行天堂岛现有 `RLP.autoplay()` 验证入口；若需要逐帧精确调整，后续必须补充 `dev/common/ref/` 参考素材后再做。
