# 房子室内漫游、森林谜题按原作重做、小屋防剧透

## 用户反馈（截图 + 原作视频）

1. 盘子特写角度不对，应该从正上方俯视桌上的虾；点虾时虾里钻出一条虫（按本作逻辑是第 2 条水蛭）。
2. 房子里也要能自由走动；墙上两幅画点击后全屏放大，方便细看。
3. 已经拿到装满血的壶之后，水泵上的壶模型应该消失。
4. 山羊旁边少一个木桶：用装血的壶把血倒进木桶，山羊去喝，舌头上粘着一条水蛭。
5. 用装血的壶给父亲的杯子倒满，父亲喝完杯底留一条水蛭；四条水蛭集齐 → 猫头鹰给钥匙 → 打开小屋。
6. 小屋要细致建模：之前从侧面能看到门后的黑影（灵魂），剧透。
7. 参考 `dev/ref/P01_第一灾_BV1bo4y1y7fm.mp4` 抽帧核对：盘子俯视、虾裂开；父亲举杯、倒血后喝完；山羊侧身对着木桶；画全屏；灵魂只在小屋门打开后从门里看到；给父亲倒完后空壶仍留在物品栏。

## 设计决策

- **室内漫游**作为通用能力放进 `views`：视图 `roam: true` 且不是特写 / fixed 就是开放视图；`views.defineRoamArea(zone, { bounds, circles, boxes, eye, floor })` 定义走动范围。漫游位置按区域记忆：从外面进门总站在门口机位；从同区域特写返回恢复原位；出门回到进门前的室外位置。漫游位置不写存档。
- 房子布景从“三面墙的舞台”改成**封闭房间**：两侧墙、带门洞的前墙、门框、门外亮光、门槛和门外一小块地面、天花板和横梁、墙角墨线。
- 盘子特写改为相机在盘子正上方 0.82 m 俯视（fov 36）；**点虾本身就能裂开**（砍刀也可以），不再要求砍刀。
- 两幅画用 `makeHangingFrame` 新增的 `snapshot()` 合成一张画布（画框正面 + 画 + 内阴影 + 铭牌），`ui.viewImage()` 从画在屏幕上的位置放大到画面中央（FLIP 动画），点任意处 / ▼ / Esc / S / ↓ 关闭；打开期间不能走动和转身。
- 水泵：放上空壶 → 压一下灌满 → 壶直接回到物品栏（`jug_on_pump` 清空，泵上不留壶）。若中途存档导致壶留在泵上，空手点水泵会接着灌满并交还（旧存档在 `sync` 里自动纠正）。
- 木桶放在山羊嘴下（`layout.js`：山羊 `rotY = π/2` 侧身朝东，木桶在身前 0.7 m）；倒血用 `replace('jug_blood', 'jug')`，空壶留在原格子。山羊喝水姿势重调：脖子朝前下方伸、头再低，嘴伸进桶里（原姿势头往回勾、嘴在桶外）。
- 父亲的杯子初始为空；对父亲使用装血的壶 → 切到父亲特写 → 倒到 2/3 → 喝完（从当前液面开始喝）→ 杯底露出水蛭 → 点杯子拿走；空壶留在物品栏（与原作一致）。没拿壶时点父亲说“给我弄点喝的来”。
- 猫头鹰给钥匙后嘴里的钥匙模型隐藏。
- 灵魂在 `shed_open` 之前隐藏（`lake.js` 监听 flag 并在 `sync` 恢复），加上小屋改成封闭建模（侧墙、后墙带门洞、单坡屋顶），侧面和背后都看不到门后的黑影。
- 顺带修正同类问题：船上箱子的线卷拿走后从箱子里消失，箱子只给一次东西（线绑上竹竿后再点箱子不会再给一卷线）；虫子从果子里爬出后随即飞进物品栏、果子上不再留着。
- 漫游碰撞：正面顶住圆形障碍（圆桌、树干、山羊）时，按轴拆分会卡住不动；新增 `slideAround()`，把这一步按 ±0.3…±1.3 rad 由小到大转向，沿障碍边缘绕过去（速度乘转角余弦）。按轴滑动只在该轴还剩一半以上步长时优先使用，避免零长度的轴向移动把速度清零。
- 山羊舌头上的水蛭、玛格丽特手里的水蛭各有一个点击球，原来用 `mesh.visible = false` 隐藏，热点射线会跳过；改成材质不可见 + `userData.proxy`（和 `makeProxy` 一致）。

## 修改的文件

- `src/core/views.js`：室内漫游（`roam`、`defineRoamArea`、按区域的站立 / 视线高度 / 碰撞 / 记忆）、`go()` 三种情况重写、`slideAround()`。
- `src/core/hotspots.js`：漫游时只开放当前区域里开放视图的热点。
- `src/core/ui.js`、`styles.css`：全屏看图（`viewImage` / `closeImage` / `imageOpen`，`modalOpen` 包含它，键盘关闭）。
- `src/core/debug.js`：autoplay 自动关闭全屏图。
- `src/art/buildings.js`：封闭房间、门槛；小屋侧墙 / 后墙 / 单坡屋顶，锚点 `shed.doorway`、`shed.back`。
- `src/art/layout.js`、`src/art/world.js`：山羊朝向和木桶位置，木桶 / 山羊 / 小屋墙的碰撞体。
- `src/art/props_inner.js`：画框 `snapshot()`。
- `src/art/characters.js`：山羊喝水姿势、两个水蛭点击球、父亲按当前液面喝。
- `src/chapters/plague1/forest.js`：房子视图与走动范围、门内出口、画、盘子、父亲、水泵、木桶、山羊、猫头鹰；`sync` 与 walkthrough。
- `src/chapters/plague1/lake.js`：灵魂在小屋门打开前隐藏。
- `src/chapters/plague1/beach.js`：线卷 / 虫子拿走后从场景消失，箱子只给一次。
- `src/chapters/plague1/text.js`：房子提示（电脑 / 触屏）、虾裂开、木桶、两幅画标题。
- `README.md`、`AGENTS.md`：操作说明、森林流程、自动流程步数、室内漫游规则。
