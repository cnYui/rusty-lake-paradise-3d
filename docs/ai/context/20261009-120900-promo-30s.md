# 30 秒宣传片（用户实况录屏 + Family Tune）

## 用户要求

用 `C:\Users\yui\Downloads\屏幕录制 2026-10-09 115044.mp4`（用户自己录的游戏实况，5 分 41 秒，1918×930）当画面，
下载 B 站 BV1s44y1B7Jr《【锈湖】Family Tune歌曲无限循环。一家人的宿命，只为复活一人。》当 BGM，剪一条 30 秒宣传片。
（小红书小工具用户已自己点了发布。）

## 做法（`dev/promo/make_promo.py`，可重新生成）

- BGM：`yt-dlp -f ba` 只取音频（`bgm_family_tune.m4a`，14.5 MB，15 分钟），没有用登录信息，链接里的跟踪参数没用。
  分析：约 60 BPM、3/4 拍（1 拍 1 秒，1 小节 3 秒），整曲循环约 54 秒，拍点相位 0.18 s。取 0.18 s 起 30 s = 10 小节，拍点落在整数秒上；
  淡入 1 s、淡出 3 s，加 +2 dB 并限幅，成片 −14.6 LUFS、峰值 −1.0 dBFS。输出音频里重新测的拍点相位是 0.00 s，说明剪辑点踩在拍上。
- 画面：录屏里游戏区域（含右边物品栏）裁成 16:9（`crop=1526:858:181:36`）放大到 1920×1080、30 fps；只用画面，录屏里的游戏声音不要。
  1 小节（3 s）一个大镜头，蒙太奇 1 拍（1 s）一个，镜头之间 0.12–0.5 s 溶解（`xfade`），开头从黑淡入。
- 镜头（录屏时间）：岛和“第一灾 血灾”(0:01) → “自从收到母亲的死讯”(0:07) → 门 / 船 / 血湖(0:22 / 0:25 / 0:29) → 玛格丽特(1:41) →
  父亲 / 卡罗琳画像 / 艾兰德一家全家福(2:25 / 2:32 / 2:34) → 父亲喝血“自从你母亲走后……”(3:18) → 山羊 / 猫头鹰 / 灵魂(3:59 / 4:17 / 4:56) →
  棺材冲出血池 / 整口棺材 / 棺盖打开露出黑方块(5:07 / 5:12 / 5:15) → 一家人（刚重做的模型，慢推）(5:19) → 神殿(5:28) → 片尾卡。
- 字幕：游戏自己的剧情字幕保留；加了两句（“血色的湖，沉默的岛”“一家人的献祭，只为唤回一人”，Noto Serif SC，底部带渐变垫底），
  片尾卡“锈湖：天堂岛 3D / 第一灾 · 血灾 / 小红书小工具 · 同人作品，非官方”。
  “母亲走后，这个家变了”一句试过，会和游戏里画像 / 全家福的铭牌重叠，去掉了。

`dev/promo/锈湖天堂岛3D_宣传片_30s.mp4`：30.000 s，1920×1080，H.264 CRF 17 + AAC 192k，33 MB。
