## 重做前的问题

用 `dev/cast.html?preset=current` 把旧模型按各章实际缩放并排：同一个人在不同章节身高从 1.18 m 到 2.39 m（第四、五灾用 0.65–1.5 的缩放凑镜头）；身体是车床旋转体和胶囊管拼接，袖子像圆木、肩膀是凸出的球，布料贴图满是竖条纹像木纹；坐着的人物裙子要靠顶点硬改。

## 新结构

- `src/art/charkit.js`：从 `characters.js` 拆出的底层工具（材质、贴图、几何体、脸部绘制、IK、放样）。关节改为 `THREE.Bone`，新增 `skinMesh` / `chainWeights` 和 `rig.bindSkins()`。`rig.apply()` 在有蒙皮时同步骨骼矩阵并清空包围盒缓存，保证不渲染时（自动测试 `norender=1`、读档后立刻点击）射线和包围盒也是当前姿势。
- `src/art/human.js`：`bodyDims(身高)` 按比例推骨架；`torsoSkin` / `limbSkin` / `skirtSkin` 生成连续蒙皮衣物（衣身按高度在脖子 / 躯干 / 髋之间过渡，肩部带上臂权重；袖子、裤腿沿骨链过渡；裙子前片跟随大腿和小腿）；`head`（变形头骨 + 手绘脸部贴花 + 立体鼻子和耳朵）、`hands`、`shoes`、`feltHat`、`lockGeo`、`fabric`（平涂 + 稀疏墨线褶皱）；`lifeIdle`（呼吸、重心转移、隔几秒换注视方向）和 `playKeys`（多关键姿势动画）。
- `src/art/cast.js`：全部人物和章节变体，方法名与旧接口一致（`setRod` / `castAndCatch`、`setNose` / `holdLeech`、`drink` / `hideGlass`、`swallowKey` / `drinkSoup` / `holdBowl` / `vomit`、`holdFlute` / `playPhrase`、`raiseCube` / `burstCube` 等）。新增：`david_p2`、`gerard`（`curlUp`、`sit`、`eatBurger`）、`nicholas.holdCube` / `setBandage` / `restHandOn`、`margaret_pot`、`margaret_cook`、`margaret_chef`、`jakob_child`。
- `src/art/characters.js`：只保留面具、山羊、开场小船、`makeCharacter` 和 `CHAR_KIT`（旧工具名继续导出，第三灾工作树用到的 `createRig` / `skeleton` / `addHead` / `paintPlain` 等仍可用）。`characters_p2.js` 变成空的兼容模块，`chars_p2_*.js` 删除。

身高（头骨顶）：Nicholas 1.88、Gerard 1.84、David 1.78、Jakob 1.76、Caroline 1.66、Ida 1.58、Margaret 1.56（驼背约 1.47）、Elizabeth 1.32、少年 Jakob 1.30、灵魂约 1.97。全部章节 `scale = 1`。对照图：`dev/shots/cast/lineup-family.png`（新）与 `lineup-before.png`（旧，按章节缩放）。

## 章节改动

- 第一灾：Nicholas 坐在高背椅（座面 0.49）上，酒杯换到靠桌子的左手、举到脸旁；Margaret 坐凳子，裙子按坐姿建成搭在膝上的裙兜。点 Margaret 时补上原作的鼻中水蛭：第 1、2 下探头，第 3 下停在鼻孔，第 4、5 下往外拉，第 6 下捏出来递给玩家；`sync()` 按 `nose` / `margaret_leech_taken` 恢复。
- 第二灾：五个角色直接用新模型（摆放和镜头不变）；碗的特写按新 Gerard 的捧碗位置取景。
- 第四灾：地坑里改为蜷着侧躺的 Gerard（以头和髋中点对准坑心，坑口放大到 1.3 倍、碰撞半径 0.9）；奶奶用 `margaret_pot` 坐在锅里，裙子和鞋藏在锅里不显示；父亲按 1 倍坐在 1 倍高背椅上双手捧方块（方块挂在两手之间）；回忆改为父亲坐在新加的木凳上、左手搭在少年 Jakob 肩上（原来是缩小的 David）。
- 第五灾：奶奶站在砧板后举菜刀，定期剁一下（厨房碰撞盒移到她脚下）；Gerard 与满头绷带的父亲坐在餐桌后（桌子较高，坐高 0.6，腿藏在桌布后），餐厅镜头放低拉近；给 Gerard 汉堡时先播放双手捧汉堡吃完的动画再进入厕所；厕所里 Gerard 坐在木板座位上双手搭膝，回忆圆盘挪到后墙他头顶上方。
