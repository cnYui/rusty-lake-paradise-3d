# 第二灾 40 秒短片（按 BGM 节拍剪辑）

时间：2026-10-19 08:39

## 需求

用户给了 B 站视频 BV13t421j7xY（JLRS日落fm 翻唱的《Family Tune / 最后一支舞》），要求下载其中的 BGM，用上一轮录的第二灾通关演示剪一条 30–40 秒的游玩视频：开头先放第二灾“蛙灾”标题，再接实际演示片段，镜头切换跟着音乐节奏，剪辑从简。

## 做了什么

1. 下载：`yt-dlp -x --audio-format wav` 把音频下到全新的空目录（scratchpad 的 `bgm_dl/`），得到 48 kHz 立体声 wav，151.6 秒。已复制一份到 `dev/shots/plague2/trailer/bgm-family-tune-cover.wav`（`dev/shots/` 被 `.gitignore` 忽略，不进仓库）。
2. 节拍分析：本机的 `librosa` 因 numba 与 numpy 2.5 不兼容无法导入，没有去动全局环境，改用 numpy + scipy 自己做（谱通量求起音，自相关估速度，再网格拟合）。结论：**120.0 bpm、3/4 拍（华尔兹）**，一小节 1.5 秒，小节线在 `0.04 + 1.5·n` 秒；每 8 小节（12 秒）换一段，24 秒起变响。第一版网格搜索得到过 60 bpm，是稀疏网格得分偏高的退化解，限制到 100–140 bpm 后稳定在 120。
3. 剪辑：`dev/make_plague2_trailer.py`（一条 ffmpeg 命令，输入是演示录像里的秒数 + BGM）。25 个镜头，全部硬切、对齐小节线：
   - 0–3 秒：片头标题“第二灾 / 蛙灾”（从黑场淡入，对应音乐前奏）
   - 3–12 秒：海滩 → 湖边 → 睡莲两关 → 蛙卵盆 → 蛙卵沉下（前奏，每小节一切）
   - 12–24 秒：青蛙浮起 → 厨房 → 神殿 → 转盘锁 → 蛙笛 → Ida 吹笛（中段）
   - 24–37.5 秒（变响）：David、吃青蛙、锅里放青蛙、点火、Gerard 举钥匙、碗里的钥匙、回忆、吊架、画里的光
   - 37.54 秒：结尾卡“第二灾 · 完”，画面和音乐一起淡出，全片 39.57 秒
   - 音频：BGM 从头播放（不用演示录像自带的声音），`loudnorm` 到 -16 LUFS，开头 0.5 秒淡入、结尾 2.2 秒淡出。
4. 校对：按每个镜头抽帧检查，调整了三处素材起点（Ida 头顶的青蛙要是橙色、Gerard 要拍到举起钥匙、碗里的钥匙避开黑场过渡）。切点处抽帧确认落在小节线上。

## 成品

- `dev/shots/plague2/trailer/plague2-trailer.mp4`：1920×1080、30 fps、H.264 + AAC，39.57 秒，约 12.4 MB。
