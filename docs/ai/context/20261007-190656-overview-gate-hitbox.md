# 总览入口真实点击修复

## 现象

总览画面中的黑色树林入口由 `overview_gate` 热点负责跳转到海滩近景。自动 walkthrough 直接调用热点 API 可以通过，但真实鼠标射线只命中入口投影中约 60×40 像素的区域；点击可见门洞边缘时没有反应。

## 决策

将 `overview_gate` 的不可见代理从 `[0, 0.5, 40]`、`8×5×2` 扩大并上移到 `[0, 3.5, 40]`、`12×8×3`，覆盖门柱、门楣和门洞的完整可见范围。代理仍只注册在 `overview` 视图，因此不会遮挡海滩近景的其它热点。入口点击改为即时进入 `beach_mid`，避免总览到近景的长距离平滑移动在低帧率下看起来像没有响应。

## 验证计划

- 用 Playwright 真实 `page.mouse.click()` 点击总览入口的中心与边缘，确认视图进入 `beach_mid`。
- 运行 `RLP.autoplay()`，确认第一章流程和 `plague1_complete` 旗标不受影响。

## 同步检查中发现的坐标问题

存档恢复检查发现森林 `add()` 也把数组传给了 `Vector3.copy()`，令水泵、桶、猫头鹰和小屋门的根节点坐标成为 `NaN`。已让该辅助函数同时处理数组和 `Vector3`，否则自动 walkthrough 虽能调用热点 API，真实射线无法命中这些道具。
