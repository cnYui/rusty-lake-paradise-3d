# 2026-10-28 第三灾：白桦林进去出不来

## 现象
玩家（小红书小工具，竖屏触屏）进了白桦林（zone `p3_grove`，可漫游）之后找不到出口。

## 原因
1. 白桦林是 roam 视图，`views.refreshArrows()` 在漫游时不显示箭头，所以没有 ▼ 返回（设计如此，core 不改）。
2. 唯一出口 `p3_grove_exit` 是一个看不见的 3.4×2.8 代理盒，放在出生点（相对 [0,0,6.4]）身后 1.1 m 的空地中间；玩家出生面朝 −z，出口在背后，那里什么都看不见。
3. `props_p3_grove.js` 的 `buildRoam()` 外圈挡圆（半径 7.1、r 1.15，正南 i=0 在相对 (0,12.5)）把南面入口缺口也堵死了，走过去也出不去。

## 修改
- `src/art/props_p3_grove.js`：`buildRoam()` 去掉正南的挡圆，相邻两颗（i=1、27）外移到半径 7.8，南面留出走廊；两侧仍被挡住。
- `src/chapters/plague3/world.js`：
  - 在白桦林南面相对 z=12.4 摆一个 `p3_grove_portal`（rotY = π，白桦 + 亮雾），亮雾挪到树干之间（`portal_fog.position.z = 0`），从空地里能看见；存为 `W.groveExitPortal`。
  - `p3_grove_exit` 热点挪到缺口前（相对 [0,1.4,11.6]），id 不变。
  - 新增“走出去”触发：`ctx.engine.onUpdate` 里漫游位置相对 |x| < 1.6 且 z > 10.8 时 `ctx.go('forest_clearing', { fade: true })`，`groveLeaving` 标志保证只触发一次，setup 重复调用前先取消旧订阅。再进林子仍站在入口（非 exterior zone 不恢复漫游记忆），不会一进来就被弹出去。
- `src/chapters/plague3/text.js`：`hintGrove` / `hintGroveTouch` 补“转身从南面的缺口原路返回”。
- `dev/plague3/test_plague3_browser.py`：新增 `test_grove_exit`——桌面真实鼠标点入口 / 出口、按住 ArrowDown 走出去（只触发一次、再进出生点仍在入口）；竖屏 390×844 触屏轻点入口 / 出口、CDP 摇杆向下拖走出去。全程不用传送进出白桦林。
