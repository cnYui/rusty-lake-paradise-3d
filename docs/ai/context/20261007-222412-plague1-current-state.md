# 第一章当前实现与玩法记录

## 项目状态

当前项目是基于 Three.js 原生 ES modules 的 3D《锈湖：天堂岛》第一章「血灾」原型。第一章的海滩、森林、湖区和神殿流程已经串通，章节结尾旗标为 `plague1_complete`。

本地试玩地址：`http://127.0.0.1:8080/`

自动测试地址：`http://127.0.0.1:8080/index.html?autotest=1`

## 当前玩法

### 海滩

1. 从总览点击黑色树林入口进入海滩。
2. 进入船附近并打开船上的插销盒，获得弯刀、鱼钩和鱼线。
3. 用弯刀砍竹子，获得竹棍。
4. 用弯刀连续砍尖刺果实五次，获得虫子。
5. 将竹棍分别与鱼线、鱼钩、虫子组合，制作鱼竿。
6. 用鱼竿在血湖捕虾。
7. 点击天堂门打开上下机关并伸出门里的手。
8. 将虾交给门里的手，进入森林。

### 森林

1. 点击玛格丽特的鼻子取得水蛭。
2. 进入房屋，切开盘中的虾取得水蛭。
3. 打开柜子插销取得水壶。
4. 用水壶从水泵抽血，再把血倒进桶里。
5. 让山羊喝血取得水蛭。
6. 把血水壶交给父亲取得水蛭。
7. 将四只水蛭喂给猫头鹰，取得钥匙。
8. 用钥匙打开小屋并进入湖区。

### 湖区与神殿

1. 与灵魂对话两次。
2. 在血池点击棺材使其升起，再次点击进入棺材近景。
3. 在近景拔掉六枚钉子，取得黑方块。
4. 点击打开的棺材进入记忆场景，再返回湖区。
5. 进入湖岸和神殿。
6. 打开翼形装置，放入黑方块并关闭装置。
7. 点击喷泉查看倒影，再次点击翼形装置使其下降。
8. 点击画作净化画面，再次点击画作框选青蛙，完成第一章。

## 交互方式

- 室外普通视图按住 `W/A/S/D` 进入自由漫游。
- `W/S` 前后移动，`A/D` 左右移动，按住 `Shift` 加速。
- 鼠标位置控制漫游时的水平和垂直视野。
- `Esc` 退出漫游并恢复当前固定镜头。
- 点击船、门、人物和道具仍使用热点射线交互。
- 室内、船内、棺材近景和神殿特写继续使用固定镜头、鼠标点击和方向箭头。
- 物品操作需要先点击物品栏选中物品，再点击目标热点。

## 已知限制

漫游碰撞目前使用岛屿轮廓和天堂门栅栏门禁，树木、建筑外墙等装饰物没有统一碰撞体。漫游是室外辅助探索模式，章节谜题仍依赖固定视图和热点；室内区域不会进入自由相机模式。
