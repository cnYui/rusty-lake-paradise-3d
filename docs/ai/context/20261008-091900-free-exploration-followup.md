# 总览拉近后的自由探索

## 需求

保留从远处总览天堂岛、点击天堂门后拉近到海滩的体验；拉近完成后立即进入完全自由的室外探索，取消海滩普通视图的固定机位控制。

## 实现

- `src/core/views.js` 的漫游相机使用左侧游戏画布的指针拖动像素增量累计水平角度，yaw 不设上限，可连续旋转 360 度以上。
- 自由探索只在 `overview` 成功进入 `beach_mid` 后启动，避免总览画面、存档恢复或其他固定室外视图被自动改写。
- WASD/Shift 移动继续经过岛屿轮廓和天堂门禁检查；进入室内、谜题近景或其他 `views.go()` 目标时退出自由模式并恢复目标固定镜头。
- `src/core/ui.js` 的数字键 `1` 至 `6` 复用 `selectSlot()` 选择物品栏槽位。

## 验证

- `node --check src/core/views.js`
- `node --check src/core/ui.js`
- `dev/shot.py` 在本次环境中未返回有效诊断，浏览器端 `RLP.autoplay()` 未能完成执行，需在可用浏览器运行环境中复核。
