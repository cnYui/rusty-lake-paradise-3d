# 2026-10-23 用 AI 生成的网格模型替换人物 / 山羊 / 牛 / 苍蝇人

## 背景

用户用 Tripo 生成了 9 个 GLB（每个约 200 万面、60 MB、T 字 / A 字姿势、没有骨骼、归一化到最大边 ≈ 1），要求按“现实比例对照图”（`docs/art_scale_chart.png`、`src/art/scale.js` 的 `HUMAN`）替换游戏里的人物建模，并说明缺哪些人物；山羊要去掉木盆（游戏里有自己的木桶道具），牛是第五灾的牛。

## 对应关系

| --- | --- | --- |
| historical+judge+character | Nicholas | 1.88 |
| historical+character | Gerard | 1.84 |
| cowboy+character | David | 1.78 |
| cartoon+grandmother | Margaret | 1.56 |
| historical+woman（红发、棕裙） | Ida | 1.58 |
| cartoon+man（白衬衫、灰裤、靴子） | 少年 Jakob | 1.30 |
| cartoon+goat | 山羊（第一灾） | 肩高约 0.85，鼻尖到尾 1.1 |
| cow | 牛（第五灾） | 高 2.3（世界里 ×1.25，同程序化牛） |
| anthropomorphic+fly | 苍蝇人（第四灾） | 头骨顶 1.9，含翅膀 2.6 |

**还缺的人物模型**：Caroline（1.66，条纹帽、青色衬衫）、Jakob 成年（1.76）、Elizabeth（1.30–1.32，也是 `elizabeth_pheasant`）、灵魂（1.97）；另外变体 `nicholas_deer`（穿长袍）、`gerard_young`（年轻、无帽无胡子）、`ida_child`（小 Ida）、`nicholas_stand`（第三灾回忆里换了衣服颜色和发型）、`gerard_barber`（第三灾剪耳朵，要从头部网格里拆出耳朵）和成年模型对不上，继续用程序化建模（`rlpm.js` 的 `PROCEDURAL`；`nicholas_stand` / `gerard_barber` 一开始用了模型，截图里头没了，才排除）。没有 Caroline / Elizabeth 的模型之前，这两位仍是程序化人物，造型会和新模型不一致。

## 做法

1. **减面 + 烘贴图**（Blender，`dev/common/models/retopo_bake.py`）：直接减面会卡在 12 万面（AI 模型 UV 接缝极碎），所以先焊接、减到 4 万面、`Smart UV Project` 重展 UV，再把原贴图用发光烘焙烘到新 UV（2048²，导出 JPEG q86）。山羊的木盆是单独的连通块，按位置删掉（`filters.py`）。
2. **绑骨骼**（`rig_export.py` / `goat_export.py` / `fly_export.py`）：地标（肩、肘、腕、髋、膝、踝、颈、下巴）对着带网格线的正面渲染图读出来，写在脚本里。人物绑定到和 `charkit.skeleton()` 完全一致的 14 个关节，`k`（骨架比例）写进文件头，`makeHuman` 直接用它建骨架，`rig.dims` / `rig.Y` / IK / `seatedPose` 全部自洽。权重：Blender 自动权重（热扩散）能用就用，玛格丽特的网格不封闭、全部失败，改用“到骨骼线段的距离反比”权重；裙装（Margaret、Ida）髋以下单独算：身体 + 前面随大腿 / 小腿摆动，最下面一圈是鞋，整个跟脚走。
3. **绑定姿势**：模型是 T 字 / 八字腿，但游戏里的休息姿势是手臂下垂、腿并拢。每个关节带一份绑定姿势（世界位置 + 绕前向轴的转角），逆绑定矩阵由它直接算出（`rlpm.js` 的 `boneInverses`），所以不需要重摆网格，也不改任何章节里的姿势数值。腿并拢后身体会抬高一点（`delta0`），缩放时已经算进去，休息姿势下头骨顶 = 表里的身高。裙装的腿藏在裙子里，绑定时就是竖直的，鞋子靠脚关节整体平移到身体下面。
4. **运行时**（`src/art/rlpm.js`）：自定义二进制 `.rlpm`（头部 JSON + 顶点 / 法线 / UV / 蒙皮索引 / 权重 / 索引）+ 烘焙贴图 JPEG。`cast.js` 的 `manBody / nicholasBody / margaretBody / womanBody` 开头调 `modelHuman(id)`，有模型就返回网格人物，否则走原来的程序化建模，所以没加载成功时自动回退。头（含头发、帽子）单独一块网格，`headTags` 照旧能隐藏（换动物头）；手只能整体跟着手腕转，`setHand` 只记录；脸没有表情贴花，`rig.face` 是占位对象。`main.js` 在章节 `setup` 前按 `CHAPTER_MODELS` 预加载模型。
5. **动物与苍蝇人**：山羊（`goat_model.js`）关节名和动作（`drink` / `tongueLeech` / `flinch` / `bleat` / 咀嚼 / 耳朵 / 尾巴）与程序化山羊一致，绑定姿势就是站姿，喝水姿势用脖子 + 头的两连杆 IK 求出，让嘴够到前方 0.7 m 的木桶；舌头和水蛭仍是程序化部件挂在 `tongue` 关节上。牛（`cow_model.js`）是静态网格，网格名 `cow_body`，谜题用的彩色斑点和肉的伤口是叠在牛身上的小圆片（射线贴到真实表面），`setState({ cured, meat })` 照旧。苍蝇人（`fly_model.js`）13 个关节（pelvis / torso / head / 双臂 + 前臂 / 双腿 + 小腿 / 双翅），`setKneel` / `kneel` / `update`（翅膀扇动、悬停起伏）与程序化版一致。

## 体积

每个模型约 1.1–1.3 MB（`.rlpm`）+ 0.6–0.85 MB（贴图），全部 9 个共 16.6 MB，每章只加载自己用到的（约 3–6 MB）。游戏本体 `src/` 之前是 2 MB，网页部署（`deploy_mac.sh` 整个拷贝 `src/`）会带上 `src/art/models/`。

## 已知限制 / 后续

- 小红书小工具、口袋方舟包（`dev/minitool/build.py`）还没带上模型文件：esbuild 打成 iife 后 `import.meta.url` 不可用，加载器会回退到程序化模型，所以现有打包不会出错，但包里仍是旧造型。要带上新模型需要给 build.py 加资源拷贝和预加载路径，并重新评估包体积（网格人物每章约 3–6 MB）。
- 手不能换形状（握杯、指点都是同一个手形）；脸没有眨眼 / 说话 / 痛苦表情；网格人物的头包含头发和帽子，换动物头时整块隐藏。
- 裙装的下摆在坐姿下是近似的（前面随大腿 / 小腿摆，后面不动），特写里可能有轻微穿插。
- 射线点击走 SkinnedMesh 逐三角形（每个约 4 万三角形），目前没有性能问题；如果以后加更多人物同屏，可以改成低模碰撞代理。
