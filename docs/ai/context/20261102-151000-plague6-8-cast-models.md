## 实现

- `src/art/cast_mock.js`：`makePerson(id)` 查 `REAL` 表，用 `cast.js` 的 body 函数 / `makeCharacter` 建人（`gerardBody`、`davidBody`、`nicholasBody`、`margaretBody` 是网格，模型没加载就自动回退程序化；Ida 藏青蛙、鹿头人藏黑方块、Caroline 藏婴儿），`adapt()` 套上占位人物的接口：`setPose('stand'|'sit'|'lie'|'kneel'|字典)`、`POSES`、`basePose`、`reach(side, pos)`（在基础姿势上解手腕 IK）、`setHeld`、`parts.body = root`、`parts.head = 头骨骼`。躺是绕髋关节转 90°（不转 root，挂在 root 上的第六灾胸口模型不受影响）；坐时手搭在大腿上；跪是大腿竖直、小腿平放、双手胸前合拢。灵魂的骨架没有 `rig.Y`，只给站姿。
- `rlpm.js`：`CHAPTER_MODELS` 加 `plague6 / plague7`，`plague8` 补上人物模型；`PROCEDURAL` 加 `gerard_p7`（第七灾玩家要拿走 Gerard 的帽子，网格的帽子长在头部网格上摘不下来，用程序化 Gerard，`showTag('hat')` 控制）。
- 第六灾：病人躺床、奶奶坐凳、回忆里交出病心后鹿头人用 `reach` 把心举到少年 Jakob 头顶。
- 第七灾：门外和滑冰台面的人物换成 Ida，神殿里 Caroline 跪着、鹿头人用自带的 `hold` 姿势举右手。
- 第八灾：`holdMandolin` 把曼陀林挂在 root 上（琴颈朝左上），两手 IK 到琴颈 / 琴身，右前臂每帧小幅摆动当拨弦；David 帽子上挂两根羽毛（按 `david.rlpm` 头部顶点量的帽冠位置）；Ida 的眼睛盖两片圆片，拿到羊眼睛前白、之后金（位置 `IDA_EYES` 是在 `p8_seer` 特写里用射线量的；`rig.noseTip` 在 Ida / Margaret 的网格上找到的是刘海 / 眉眼，不能用来定位嘴眼）；`grandmaHorn(on)` 把号角挂在奶奶头骨骼上贴着嘴、右手扶号身。
- 第八灾木盒：Nicholas 的模型有八字胡，III 的属性 `[0,0,1,0]` → `[0,1,1,0]`，答案从第 4 列变成第 2 列（开局 1、2、3 列仍没有一个对），谜歌第三句加上“两撇细胡子”，设计文档和规则测试同步改。
