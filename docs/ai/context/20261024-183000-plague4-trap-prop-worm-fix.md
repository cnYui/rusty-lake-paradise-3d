# 第四灾鸟陷阱：树枝撑不住石板、虫子放不上（2026-10-24 18:30）

## 玩家反馈
小红书评论：“这个盘沿怎么支不起…”，截图里石板翘起了，树枝却立在板头外面，虫子点了也放不上。

## 原因（浏览器真实鼠标 / 数字键复现）
1. `props_flies.js` 的 `buildTrap`：石板翘起 0.5 rad 后板头在 x≈0.37，树枝立在 x=0.4、顶高 0.42，**没顶到板底**，看起来树枝悬在旁边，石板像是自己立起来的。
2. `story.js` 的 `bird_trap`：树枝共三根，`ctx.take('branch')` 后库存里还有树枝，选中状态保留。玩家紧接着点虫子槽位，等于“树枝 + 虫子”合成，失败后晃一下并取消选中，看起来就是“点虫子没法放置”（要再点一次才选中虫子）。
3. 热点只有石板和树枝的网格：虫子放在板下，玩家会点板下的空地，射线打空没有反应。

## 修改
- 树枝改到 x=0.27、顶高 0.41，正好顶在翘起的板底（`props_flies.js`）。
- 放树枝、放虫子的处理函数里用完立刻 `noItem(ctx)` 取消选中（`story.js`）。
- 给 `W.trap` 挂一个看不见的点击代理（0.6×0.32×0.42 m，罩住翘起的石板和板下空地），热点范围变大（`story.js`）。

## 验证
- 脚本：选树枝点石板 → 选中状态清空；按虫子槽位 → 选中虫子；点板下空地 → `p4_trap_baited` 立起。截图里树枝顶住板底，虫子在板下。
- `node --test dev/plague4/test_plague4.mjs` 19 项全过；`python dev/plague4/test_plague4_browser.py` 无页面错误。
